## 1. 实际问题

当前“显著性”包含两部分：结构统计重要性与冻结语义支持；它不是独立的人体检测器，也不保证重要性图覆盖整个人体。

- **图11有真实漏识别案例。** 一名约14×37像素行人的框内，512模型行人响应均值约0.0065，没有像素的最高响应类别为person；当前细候选在框内的脊线平均强度仍约0.92。主要问题是已有边没有获得足够权重，不能归为完全没有提取到边。
- **图18有窄行人漏识别与弱化。** 两个约7×31、7×27像素行人的person响应均值约0.082、0.052，均无person最高响应像素；原细候选较强，现有输出在这些脊线上的平均强度仅约0.271、0.260。
- **图31近处骑行者已有明显person响应。** 关注不均与局部弱化仍存在，不能把整个人归为完全漏检。其旁边的车辆也参与联合重要性，因此联合R亮不等于模型已完整识别人体。

上述数值使用已有FLIR框定位，框内包含背景，不是人体掩膜；“person最高响应占比”不等于人体像素召回率、IoU或检测准确率。40图共有133个可见的已有person/rider框，其中52个框内无person最高响应像素，仅作为进一步检查语义覆盖的线索。

原联合补充为：

$$R_j=R_s+(1-S)(1-D)A_0\max(R_{structure}-R_s,0).$$

因此，结构权重没有超过语义权重时无法补充；超过时，也受多个门控共同衰减。人体附近的密集候选同样可能给出较高D，原有方向一致性/对比度统计又不能判断“这里必须是人”。再经 $g(R_j)$ 调节贡献后，已有的有效边可能继续变弱。原25%脊线保底保存了部分响应，但不保证目标醒目或边界完整。

核对了既有同权重1024语义探针：部分弱行人恢复，部分大行人或人体局部反而减弱。放大输入没有增加真实信息，本轮没有把高分辨率推理直接作为解决方案，也不增加在线语义推理次数。

## 2. 本轮修改：只补充重要性，不改变提边

实现：`models/recall_semantic_edges.py`。复用早已存在的 `region_recall_importance()`，没有根据图号、框、位置或FLIR类别重新调一组参数。原函数的固定数值整理为 `REGION_RECALL_SETTINGS`，数值不变，完整配置进入新版本检查点签名。

从原始TIR计算两类结构线索：

1. 在0.7/1.0尺度上，比较梯度与邻域梯度，使用绝对分母下限0.015限制平坦噪声被放大；取两尺度支持的几何平均。
2. 在2/4/8尺度上，计算相对局部区域对比度，要求相邻两尺度均有支持；5×5邻域允许已有接触边利用附近支持，不画连接线。

将两类线索组合并轻度平滑，得到 $H\in[0,1]$。它代表局部结构支持，不代表“是人”或“边正确”的概率。

使用**当前清晰度候选**计算优势：

$$A_r=\operatorname{clip}[(E_f-0.5E_c)/0.3,0,1],$$

再构造：

$$R_r=R_j+0.65(0.85-R_j)H A_r(1-D).$$

使用实际细/粗候选的优势，保证提高R时不削弱粗候选路径。上界仍为0.85，D较大时补充较小；不要求原结构R必须高于语义R，也不把低语义响应直接解释为背景。

最终仍使用原融合公式F与原贡献函数g：

$$E_r=\max[0.25E_{raw-fine-ridge},\quad g(R_r)F(E_f,E_c;R_r,D)].$$

细/粗候选、脊线位置、0.5像素软编码参数、D和原细脊线保底均固定，只改变R及由R导出的g。数值上保证本候选不低于clarity_v1；固定阈值下的可见区域仍可能因变亮增加，不能把它解释为新检测出真实边界。

生成器使用 `[原始TIR, E_r, 0]`。语义推理仍为冻结512模型；P及颜色分支、Q、颜色损失均不变。本轮没有新检测器、语义纠错训练、缺口补全或结构置信度C。

## 3. 固定对照结果与代价

全40图的旧clarity_v1、R、原细/粗候选与当前源码逐像素一致；新在线接口与审查公式也逐像素一致。对照包含将旧轮廓整体提亮到新轮廓相同全图均值的一列，没有逐图归一化。

以下为已有框内、当前细候选脊线位置的**响应强度**，不是边界准确率：

| 位置 | clarity_v1 | 旧图同全图均值提亮 | recall_v1 |
|---|---:|---:|---:|
| 图11，ann23763 | 0.254 | 0.275 | 0.299 |
| 图18，ann51734 | 0.271 | 0.288 | 0.376 |
| 图18，ann51735 | 0.260 | 0.276 | 0.369 |
| 图31，近处骑行者ann23890 | 0.468 | 0.496 | 0.503 |

132个存在细脊线的框等权平均响应由0.408到0.461，同亮度对照为0.431；其中110个高于该对照，22个没有超过。另一个框没有当前细脊线，不计入此项统计，不能声称已被补回。

全图响应均值约增加6.05%；预测植被区域的图均响应约增加7.23%，预测道路区域约增加5.58%。后两者只依据当前语义预测，不能当作真实背景误检率。这说明局部补充确实同时恢复一些叶片、路面或其他纹理，尚未实现可靠的任务级人车选择。

更强、无D限制的独立探针会增加更多背景响应，因此未接入训练选项；没有继续扫权重挑选这几张图的最优结果。当前参数复用已有固定规则，40图已经多次开发审查，不是独立验证集，更不能证明跨数据集泛化。

当前可成立的结论是：**一些已有但被压弱的行人线索得到更强贡献，且部分改善超过整体提亮。语义漏识别、真正的缺边与最终RGB收益仍未解决或验证。**

## 4. 复现与使用

在项目根目录，输出目录须为空或不存在：

```bash
python -u scripts/audit_contour_importance.py \
  --output-dir runs/edge_audit/importance_recall_seed42_v1
```

脚本读取固定原语义缓存、原joint/clarity预览与本地COCO审查信息，核对原图、分类表与原输出，不重新下载权重，不训练GAN；框只用于展示和统计。

后续新训练实验使用 `--contour-variant recall_v1`，导出时也传相同选项。其余参数沿用[从零训练流程](从零训练学得颜色先验Ubuntu完整流程.md)，使用新实验名；检查点签名和恢复检查拒绝将旧实验静默改为新版本。省略开关仍为joint512。

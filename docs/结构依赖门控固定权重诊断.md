# 结构依赖门控：固定权重抑制诊断

日期：2026-10-30。这是置信度路线的第一步：先检验减弱哪些边是否影响着色，再决定是否训练小型门控分支。当前新增网络参数为0，尚未训练可学习G，也未改动D的默认训练。

## 1. 本轮具体实现

新增独立入口`D.diagnostics.compare_edge_use`。三组共享同一个模型对象、相同CPU噪声种子42、采样参数、原始TIR及P/Q；正式D还固定原有颜色先验和语义／颜色适配器。

| 组别 | 第二通道 | 要检查的问题 |
|---|---|---|
| original | 原E | 原模型表现 |
| uniform | kE | 全图减弱是否已经足够 |
| selective | GE | 在同等总强度下，空间选择是否还有额外作用 |

`k`按**实际模型输入分辨率**计算，使`sum(resize(kE))=sum(resize(GE))`，不是让显示用PNG均值接近。匹配的是缩放后的FP32条件；骨干仍按原推理精度运行。全部计算保持原软边幅值，不二值化、不自动增强亮度。第三通道保持0，P/Q不重算、不作颜色修改。正式D中的ControlNet和SourceAdapter都接收同一个改变后的`[TIR,E_use,0]`；VAE仍编码原始TIR。

本轮G是固定规则，输出含义为诊断性的“边缘使用程度”，不是学得置信度或边缘正确概率：

\[
G=1-0.75Q_{ctx}(1-B)(0.5+0.5D)(1-0.5A),\qquad E_{use}=GE.
\]

- `Q_ctx`：原Q的局部最大池化，读取边界附近的语义支持。它不能发现高置信语义错分。
- `B`：相邻完整软语义分布的总变差，扩展到小邻域并乘`Q_ctx`。可靠的类别过渡处减少抑制，不使用固定类别编号。
- `D`：原E的局部密度；稠密内部纹理更容易被减弱。
- `A`：原TIR结构张量方向一致性和相对局部噪声的梯度支持；观测中的连贯结构减少抑制。

局部尺度按图像短边比例确定；噪声统计逐图计算，不跨batch混合。G范围为[0.25,1]；整幅Q为0时完全不减弱。不按道路、植被、人、车整类清零，不读取框、图号、固定上下位置或生成RGB，也没有根据本轮RGB结果调参。固定系数仍是待检验的启发式，不能因此宣称已具备泛化能力。

路沿、树干等结构可能被保留更多，但这只是规则的设计意图；同类内部的重要结构、弱目标仍有误抑制风险。树叶被高置信认成天空的问题，也可能继续由语义／颜色分支传播。

## 2. Mac与Windows各能说明什么

Mac没有训练后的正式D权重，也未找到完整FMB权重。本轮显式复用既有40张开发图中**冻结顺序的前4张**语义／清晰轮廓缓存，重用原单视图Q配方；这些是train侧开发图，不是新留出验证集。推理使用本地已有预训练SD1.5和Canny ControlNet，不下载新模型。

Mac预览仅检查推理、固定条件干预及输出留痕。该预训练模型没有加载训练后的D语义／颜色分支，生成图也不能代表正式D的着色效果。正式生成收益必须在Windows的训练后权重上验证。

Windows入口只接受正式D格式；会在加载大模型前校验原先验、完整检查点哈希、实际推理源码和条件配方。旧GAN或RGB预热权重不会当成正式D权重加载。`latest`表示最近保存，**不表示最优**；只有显式`-Best`才读取经验证选择的`best.json`。

## 3. Windows直接运行

更新文件：[tar.gz](../runs/exports/edge_use_probe_20261030_v1.tar.gz)、[SHA256](../runs/exports/edge_use_probe_20261030_v1.tar.gz.sha256)。包内只有新增诊断代码、Windows入口、两份说明与清单；不含权重、数据或原D训练源码。清单用于核查，不成为训练依赖。

把本轮tar放在Windows项目根目录，在之前能运行D训练的PowerShell环境中执行：

```powershell
tar -xzf edge_use_probe_20261030_v1.tar.gz -C .

powershell -ExecutionPolicy Bypass -File scripts/run_edge_use_diagnostic_windows.ps1 -ListRuns

powershell -ExecutionPolicy Bypass -File scripts/run_edge_use_diagnostic_windows.ps1
```

如果有多条run，脚本列出名称和最近更新步数，由你选择本次固定使用哪条。自动匹配同配方的TIR验证缓存，优先使用run记录的验证缓存，其次选择覆盖更多验证图的缓存。默认只跑前4张、每张3组，不训练。终端最后打印结果`index.html`路径。

如需指定之前的D Python环境，使用`-Python`。例如之前环境位于仓库内`runs/D/verify_env`时：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_edge_use_diagnostic_windows.ps1 -Python .\runs\D\verify_env\Scripts\python.exe
```

其他可选参数：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_edge_use_diagnostic_windows.ps1 -CheckOnly

powershell -ExecutionPolicy Bypass -File scripts/run_edge_use_diagnostic_windows.ps1 -Best
```

`-CheckOnly`不加载大模型、不创建结果目录；`-Best`要求对应run已有有效的`best.json`。未做验证选择时不要将最近权重称为最优。

可用`-RunDir`指定仓库外的正式run，`-Conditions`指定仓库外的原配方验证缓存，`-Prior`指定原先验，`-Step`指定已有保存步数。没有验证缓存时，按[既有验证缓存说明](../D/unpaired/BEST_CHECKPOINTS.md)先准备，配置必须与run一致；不会自动以测试集或其他缓存替代。出现源码不匹配时应使用该run对应的代码，不能删掉校验强行加载。

结果默认保存到选中run内的新`diagnostics/edge_use_时间`目录。继续未完成的同一对照需显式提供原`-OutputDir`和`-Resume`；程序核对输入、代码、运行环境及既有输出哈希后才能继续。

Mac没有PowerShell运行时，本轮Windows脚本经静态核查；其Python发现、检查点校验与对照事务有自动化检查。真实Windows/CUDA整链仍需在Windows执行。

## 4. 输出与判断

每张图同时输出：

- TIR、original/uniform/selective三张原始RGB，另保留模型分辨率原图；不调色、不锐化。
- 原E、G、均匀E和选择性E对照；浮点NPZ中另存P/Q及规则的中间证据。
- 输入输出哈希、实际E总强度、统一缩放系数、推理时间、固定参数和模型身份。
- 原E参照的结构代理、固定源P/Q下的局部色度变化，以及饱和度、色度标准差。它们是描述性诊断，不能单凭数值下降判定改善；变灰或抹掉结构也可能使色度变化减小。

先看是否减少路面／叶纹的异常色块，再检查人车数量、位置、弱边和区域边界是否受损。比较selective与uniform才开始回答空间选择的作用。4张图不能支持FID/KID结论，不在这个工具中报告小样本FID。

正式结果若显示有稳定收益，再实现小型可学习G，并单独比较输入门控与损失配合。当前输入干预不改变结构保持、内容采样、色度平滑等训练损失，不能当作联合训练已经完成。

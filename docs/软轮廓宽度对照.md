# 固定样本软轮廓宽度对照

## 范围与控制

运行 `scripts/preview_contour_widths.py`，复用原审查包的40张训练集图像、框坐标和裁剪。包括原来已评级的11项，以及其余固定重点目标和建筑全图，共130项。没有重新挑图。原审查记录保持独立。

每排从左到右：TIR、C1、软边宽度1.0、0.75、0.5；上排C2b，下排C2c。叠加强度一致，纯灰度图使用固定0～1范围，没有逐图归一化。×4只用于辅助找弱边。

所有40张图上，宽度1.0的C2b/C2c与原包保存的浮点图匹配，绝对误差不超过1e-7。置信度通道保持零。训练配置没有被这个预览脚本修改。

C2c的纹理密度、重要性会随软边宽度变化。正式行保持阈值、尺度和权重公式的参数不变，重新计算自适应权重；折叠的辅助行冻结宽度1.0时的重要性和纹理抑制图，只改变软边宽度。辅助行用于归因，不代表已经选定了新的训练方案。

## 已查看的例子：初步定性判断

以下是助手对已生成对照图的观察，不是人工真值标注，也不是边界准确率。

- `01_O01`，小行人：0.5明显减少了内部扩散，纯边缘图中内部暗区更清楚。C2c仍比硬Canny暗、宽；多尺度位置差异和真实内部候选仍可能存在。脚底缺失不能靠缩窄找回。
- `04_O08`，较大车辆：缩窄后主车身结构仍可见，边缘带更集中；目标被预处理裁剪截断，只能评可见部分。
- `05_O01`，车辆：主要轮廓仍可见，但车体与背景有大量水平候选。缩窄降低线带覆盖，不会删除这些原有候选。
- `02_O10`、`03_O04`，车辆：0.5的线带更集中，但不能据此认定完整性提高；窄边对位置误差的宽容度也更小。
- `02_O03`、`03_O02`、`04_O03`，小/弱目标：原图本身难以确定真实边界。0.5减少覆盖，但依然有杂乱或偏移线索，不应按“变细”直接评为更准确。

目前0.5是值得进一步审查的候选，0.75是折中；尚不能宣布哪一种着色最好，也未选择新的正式训练默认值。

## 三项分开评级

1. 主要可见边界缺失：0无/轻微、1中等、2严重、无法判断。
2. 边界扩散：看响应是否集中在真实边界附近，不以人体内部必须全黑为标准。
3. 疑似额外边缘：独立多余线索，与软边距离尾部、真实内部结构分开记录。

先记录原图可辨性；无法辨认、遮挡和裁剪外边界不算提边漏检。小目标按框短边≤12像素、大目标按≥32像素仅用于浏览分组，不是官方类别或质量标准。建议老师复核相同目标。

纯灰度图也不是正确性的真值。`concentration_diagnostics.json`只记录响应在固定硬候选之外的质量比例，不能称作假边率、精确率或人体内部覆盖率。

## Windows PowerShell 复现

需要原审查包、相同预处理数据、已有torch/scipy/scikit-image/Pillow环境。

```powershell
$thermalRoot = "D:\thermal"
Set-Location "$thermalRoot"

python scripts\preview_contour_widths.py `
  --base-pack "$thermalRoot\runs\edge_audit\important_contour_review_v1" `
  --ratings "$thermalRoot\scripts\contour_review_ratings.json" `
  --processed-dir "$thermalRoot\FLIR_datasets\trainB" `
  --output-dir "$thermalRoot\runs\edge_audit\contour_width_review_v1"
```

已有输出目录不会覆盖，请换新的目录名。双击输出目录的`index.html`用浏览器查看。可以复制整个输出目录到另一台机器，不能只复制HTML。评级临时保存在浏览器缓存，完成后导出`contour_width_ratings.json`；该JSON使用新的包ID，不要拿旧审查脚本汇总。

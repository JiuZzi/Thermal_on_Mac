## 3. 正向生成的数据流

主条件为`X=[TIR, clarity_v1 E, 0]`，范围为`[0,1]`，各通道坐标一致。

```text
TIR ──> 冻结FMB ──> 15类P、语义可靠性Q
  └──> clarity_v1(E内已有结构/语义重要性及纹理处理)
                    ↓
               X=[TIR,E,0]
                ├─> ControlNet条件编码器
                └─> 可训练源内容残差编码器

TIR复制三通道 ──> 冻结RGB VAE编码 ──> 内容潜变量＋源内容残差
                                                ↓
                                      加噪、完整DDIM去噪链
P ──> 语义编码与投影（受Q门控） ────────────────┤
P/Q＋原RGB GMM ──> 颜色特征与投影 ──────────────┤
                                   SD1.5 UNet＋交叉注意力LoRA
                                                ↓
                                          VAE解码为RGB_hat
```

关键实现见[FormalGenerator](../D/unpaired/model.py)和[条件／教师模块](../D/unpaired/semantics.py)。X只作为条件与源残差输入；VAE收到的是复制三通道的TIR，不会把包含E和零通道的X误当普通RGB照片编码。

可选RGB预热初始化通过首层卷积转换保留原`[E,E,E]`响应：把旧三个输入卷积核求和，放到新E通道，TIR/C通道先置零。该初始化本身不表示已经学会TIR内容，需要后续适配。

## 4. 各模块迁移到了哪里

| 模块 | 当前源码状态 | 要注意的边界 |
|---|---|---|
| 软轮廓与结构／语义重要性 | 已复用`clarity_v1`，E内已有重要性和纹理抑制 | 不是后续`recall_v1`局部重要性召回版本，不可假定最后所有弱行人改进均已迁移 |
| 独立语义条件 | P经语义编码器及多尺度投影，加入ControlNet残差 | 既影响E，也独立进入生成；语义错误可能传递 |
| 语义可靠性Q | 使用原语义可靠性计算，对语义／颜色条件门控 | Q是代理评分，不是经独立校准的结构正确率C |
| RGB学得颜色先验 | 复用原GMM统计及特征，经颜色适配器注入 | 具体支持类别以先验JSON为准；README列道路、人行道、植被、天空，不代表服装／车身真色 |
| 显式局部补边 | 未见本轮讨论的端点候选、方向路径搜索、新增来源追踪模块 | 梯度损失、神经生成或更亮轮廓不等于该补边机制已实现 |
| 结构置信度C | `confidence_enabled=false`；第三通道被严格要求全零 | 不计算E乘零；当前未训练真实C的使用能力，以后需要接入并训练 |
| JR／旧轮廓对比学习 | 当前条件构建未启用JR | 正式D的新局部自相似内容损失不是JR/CUT复现 |

`ConditionBuilder.compute()`明确调用`clarity_components(...)["clarity_v1"]`。切换到recall会改变条件配方和缓存签名，应作为新版本／对照处理，不在本次阅读中直接替换正在运行的配方。

## 5. 哪些网络训练，哪些冻结

- 固定预训练SD1.5与Canny ControlNet的完整commit。
- 冻结VAE及SD／ControlNet大部分参数；文本只在初始化时编码为固定向量。
- 训练ControlNet条件编码器、down/mid输出投影、UNet交叉注意力rank4 LoRA、源内容残差编码器及语义／颜色投影。
- 另训练RGB→TIR的ResNet9和TIR/RGB两域PatchGAN。
- FMB、RGB语义教师与GMM统计不随本轮训练更新。冻结教师参数不等于关闭对生成图的梯度，源码保留生成RGB经过教师的可微路径。

因此，当前可以称为“扩散正向生成器的无配对循环适配”。它使用扩散生成机制，同时保留对抗和循环约束；不是从零训练全部Stable Diffusion。

## 6. 无配对训练与默认损失

TIR和RGB独立采样：TIR→扩散RGB→反向重建TIR；RGB→反向合成TIR→扩散重建RGB。与独立RGB样本之间没有伪造的像素对应L1。RGB自身回放的配对关系则是真实的自配对关系。

默认权重来自[正式配置](../D/unpaired/config.json)，计算路径见[训练引擎](../D/unpaired/engine.py)和[损失源码](../D/unpaired/losses.py)：

| 目标 | 默认权重 | 源码中的作用 |
|---|---:|---|
| 两域LSGAN | 1 | 目标域真实性 |
| TIR循环L1 | 10 | 生成后可重建源TIR |
| RGB循环L1 | 10 | 反向翻译后可重建原RGB |
| 轮廓支撑／方向 | 1 | Sobel梯度支撑及方向一致，允许对比极性反转；不是像素亮度相等 |
| 同位置局部自相似对比 | 0.2 | 固定局部自相似描述子的空间对应；不是完整CUT/MIND实现 |
| 语义一致性 | 0.1 | 对生成RGB作可微教师分析，与可信源P比较 |
| GMM色度约束 | 0.01 | 原Lab色度损失，前1000更新渐增 |
| 同类低边缘区域色度平滑 | 0.02 | 相邻同类区域弱化色度割裂，在E较强处减弱平滑 |
| RGB噪声预测回放 | 1 | 每4更新执行一次RGB自配对去噪目标 |

两侧循环与回放依次反传，降低同时保留计算图的内存压力。合成TIR的E/P/Q经detach与固定前端重算；原始合成TIR张量保留梯度进入VAE／内容路径。正式图像级训练反传完整采样链，不只对最后一步求梯度。

当前默认原图360×288、batch1、`sampling_steps=10`、`strength=0.4`，实际执行4步DDIM；训练与推理采用同一采样定义。CFG默认1。仓库pilot命令中的200是优化更新数；10000只是文档中的扩大预算示例，不是epoch数或已验证最佳长度。

## 7. 比较和后续排查要保留的事项

1. D0/D1、RGB预热和正式无配对D的条件、采样和训练阶段不同，不能混作同一组消融。
2. 正式D改变了图像尺寸／增强、部分数据使用及多个辅助目标，不能把相对旧GAN的全部收益归因于扩散骨干。纯骨干对照仍需另行匹配。
3. `use_semantic`／`use_color`主要控制独立残差注入；相关损失和E中的语义可能仍启用。做“无语义／无颜色”消融时，需要定义移除哪些信息，不能只关一个开关就声称完全没有该先验。
4. 对比条件使用时仍要检查人车位置、数量、边界和语义错译。轮廓依赖、损失下降或FID改善不能替代真实性／几何验证。
5. C和显式补边仍属于后续主线；当前可微结构损失并没有替代这两项，也不保证消除错误生成。
6. 正式检查点是带配置、签名、校验与多网络权重的目录；不能按旧GAN单个`.pth`的方式混用。权重、数据、缓存和实际结果仍需独立传输与核对。

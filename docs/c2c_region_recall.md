# C2c 弱轮廓保护：第一步 R-only 原型

目标是先保护原候选中已有但被压暗的弱边界，再另行研究学习式补全与对比学习，最后才加入置信度筛选。这个分支不是语义显著性网络，也不声称能补出 Canny 候选中不存在的真实边界。

## 唯一改动：重要性 R

显式使用 `--condition_mode soft_saliency --fusion_mode direct --saliency_variant region_recall` 开启。默认 `structure_texture` 保留原 C2c 行为，旧命令无需改动。

1. 在 0.7/1.0 两个尺度计算局部相对梯度；归一化分母带 0.015 的绝对底线，避免把近乎平坦的噪声无限放大。不要求局部边缘都朝同一方向。
2. 在 2/4/8 像素尺度估计区域与邻域的相对差异，分母带 0.02 底线。使用相邻两个尺度共同支持的响应，再扩展到 5×5 邻域，覆盖附近弱接触边界。
3. 两种支持组合后，只对原 R 作有界的正向增量，最大不超过 0.85，强度系数暂固定为 0.65。此处只是局部统计代理，不能识别人、脚或道路。
4. 用 `clip((fine - background_gain * coarse) / 0.3, 0, 1)` 限制增量位置，避免提高 R 反而削弱更强的粗结构通路。这个门是候选优势保护，不是边缘置信度。

两组的三尺度／三阈值 Canny、细粗候选、纹理抑制 D、背景增益、融合公式和 0.25 细边底线完全一致。红外主通路、第三通道零值、网络结构、优化器及损失定义不变。重要性变化若用于未来 JR 训练，会改变输入先验及其派生的锚点，不能声称训练轨迹相同。

JR 默认配置签名保持旧格式；明确开启新分支才把 `saliency_variant` 写入签名与元数据，避免新先验误加载／续训旧 JR 权重。普通 conditioned 模型仍应使用新实验名，不覆盖旧实验；测试新实验时必须传入相同的分支参数。

## 先预览，不启动长训练

```powershell
$thermalRoot = "E:\上海大学\项目\thermal\Thermal_on_Mac"
Set-Location $thermalRoot

python scripts\audit_c2_region_recall.py `
  --output-dir "$thermalRoot\runs\edge_audit\c2c_region_recall_20261012_seed42" `

```

没有原审查输出的机器可去掉 `--reference-audit`，使用 seed42 的 24 张常规图和 8 张小目标挑战图；若需要严格复用样本，传入已有的 `--selection-json`。工具只用 CPU、只读取 trainB，并拒绝覆盖已有输出目录。

## 预览与判断

列顺序：红外 → 原细候选 → 旧 C2c → 整体提亮对照 → 新分支。整体提亮对照通过全图统一乘法增益与裁剪，匹配新分支的完整图平均响应；它只用于诊断，不参与训练。所有图统一 [0,1] 显示；局部裁剪复用全图结果，不重新匹配亮度。

复用旧审查时，每张旧输出、R、D、细粗候选都必须与归档浮点图逐像素完全一致，源图片哈希也必须一致。正式 ConditionedGenerator 的新分支与审查副本逐像素核对，第三通道必须保持零。

既有标注框只定位审查区域，不生成轮廓、不充当训练标签或边界真值。对未截断的行人框额外输出下部接触区域代理，它不保证是脚部，也不能算真实脚边界。常规组和挑战组分开查看。

通过标准是可见的弱边更容易追踪，且不是只靠整体提亮达成；同时记录路面、树叶等纹理的额外增强。框内平均响应和阈值变化不等于边界召回／准确率。这个原型没有训练收益、RGB 改善或真实轮廓补全的证明。

若仍只有亮度改善，下一步才针对 JR 的上下文表征和补全监督做单独实验；不把本步与对比学习、置信度或语义颜色先验一起改。

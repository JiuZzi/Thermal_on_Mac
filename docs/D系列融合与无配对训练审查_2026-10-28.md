# D系列：融合、模块输入与无配对训练审查

日期：2026-10-28。对应用户要求：Windows的原D训练继续运行；本地核查融合、各模块输入与无配对代码，修复明确问题，再讨论下一阶段。审查起点为`6aec9bc3bdcd30c849d7ce8c694343dc5174933d`及原有文档修改。本轮没有操作Windows、启动真实训练、提交Git或上传代码。

## 1. 结论与版本边界

无配对训练的基本组织正确，没有发现把随机RGB当成当前TIR真值、把生成路径全部detach、把`[TIR,E,0]`当RGB送入VAE等错误。主要问题在可靠性如何进入融合，以及语义错误可能被辅助目标反复强化。

本轮分两类处理：

- **通用正确性与诊断修复**：P/Q检查、非有限解码输出检查、逐样本条件计算、重复文件检查、颜色损失开关和日志。这些不增加网络容量，不改变默认V1对有效单样本输入的计算目标。
- **需要重新实验的两项改动**：先按Q隔离条件再卷积融合；以软语义和Q调节色度平滑。仅在新[config_review_v2.json](../D/unpaired/config_review_v2.json)显式启用。V1配置与默认入口保持原样。

这里的`D_unpaired_v2`是配置／输入签名版本，不另编研究系列D2/D3。新方案是候选，不能据小模型检查断言比Windows正在跑的V1着色更好。

## 2. 输入与信息流核查

| 输入／模块 | 当前实际输入与用途 | 核查意见 |
|---|---|---|
| 原始内容路径 | TIR复制三通道，经冻结VAE得到潜变量 | 接口合理；仍依赖RGB预训练VAE对TIR的表达能力 |
| 主条件 | 同坐标的`X=[TIR01, clarity_v1 E01, 0]`进入ControlNet与源内容适配器 | 三通道含义清楚；不计算E乘零 |

| 语义P | 冻结FMB的15类软概率 | 保留软分布，没有先转彩色标签图再输入 |
| 语义Q | 原语义可靠性代理，来自概率特征及翻转等现有规则 | 有用但未经正确率校准；高Q也可能分类错误 |
| 颜色条件 | 训练RGB学得的多峰GMM统计，经P形成token，再经适配器注入 | 没有把所有类别写死成一种RGB；特征和强度分开 |

## 3. 融合中的问题与V2处理

### 3.1 旧实现的问题：卷积之后门控不能阻止错误上下文进入邻域

旧语义分支可以写为：

\[
Z_s=\phi_s(\operatorname{Area}(P)),\qquad
\Delta_s=Q_l\,h_s(Z_s).
\]

`phi_s`包含两层3×3卷积。某处Q为零，只能关闭该处最后的输出；该处错误P已经参与卷积，可能影响旁边Q较高处。颜色分支也存在类似的上下文传播路径。这是门控位置的局限，不是证明某张树冠图错误的唯一原因。

已用受控小输入复现：只改变Q=0区域的类别概率，原版相邻可信位置的语义残差会变化。该数值是构造例子的响应，不是实拍图像质量指标。

### 3.2 新实现：先筛选、归一化聚合、逐层屏蔽，再控制注入强度

源码：[SemanticColorFusion](../D/unpaired/model.py)。V2设置`fusion_policy=quality_masked`，阈值0.1沿用现有语义最低质量量级，尚未通过调参证明最优。

定义：

\[
M=\mathbb{1}[Q>0\land Q\geq\tau],\quad W=QM,
\]

\[
P_l=\frac{\operatorname{Area}(WP)}{\max(\operatorname{Area}(W),\epsilon)}.
\]

随后对每层卷积／激活的结果乘以`Area(W)>0`的支持掩膜，最后仍用Q控制投影残差的注入幅度。归一化避免在均匀区域把Q重复乘成Q²，也避免卷积偏置在完全不支持的位置形成可传播特征。全Q=0时该分支残差为零。

颜色分支使用原先验返回的`strength`作同类处理。原strength已包含Q、受支持类别概率质量及类别支持条件；原GMM特征本身不含Q，不能把旧实现说成“原来重复乘Q”。本轮没有新增可训练层，也没有把多峰先验替换成均值颜色。

边界：隔离的是**直接语义／颜色分支内，被Q排除的P**。E自身仍由P参与生成；UNet仍会空间传播特征；高Q错分仍可能进入网络。因此不能声称最终图像中的错误语义传播已全部解决。阈值还可能排除弱小行人，需要专门检查。

### 3.3 色度平滑的问题：硬标签相同不代表语义可靠

旧色度平滑只检查相邻像素argmax类别相同，并在E较强处降低平滑。低Q区域若被共同误判为天空，仍会受到同类平滑约束，可能加强错误区域内的颜色一致性。

新`chroma_smooth_policy=quality_soft`使用：

\[
w_{ij}=e^{-5\max(E_i,E_j)}
\langle P_i,P_j\rangle
\min(Q_i,Q_j)\,
\mathbb{1}[\min(Q_i,Q_j)\geq\tau_s].
\]

它让模糊语义、低Q或跨类别邻域减少平滑；保留原色度差定义及0.02系数，不强制相同亮度。按全部邻接像素求均值，不用Q归一化掉低可靠性的减弱效果。V1继续使用原硬标签目标。

这项改动可能减少错误抹色，也可能因支持不足而减弱本来有用的平滑，需独立训练比较。

## 4. 无配对实现核查与通用修复

| 检查项 | 结论或修复 |
|---|---|
| 两域采样 | TIR/RGB独立采样，采样器状态可恢复；没有要求文件同名或像素对应 |
| 两侧循环 | TIR→RGB→TIR重建当前TIR；RGB→TIR→RGB重建当前RGB；监督关系正确 |
| RGB回放 | 用RGB自身作去噪目标，属于自配对回放，没有构造随机跨域像素标签 |
| 反向循环梯度 | 合成TIR的E/P/Q固定／detach，但原合成TIR仍进入VAE与源路径，梯度能回到反向网络 |
| 教师梯度 | 真实小型SegFormer检查确认：生成RGB得到非零有限梯度，教师参数没有梯度 |
| 分图反传 | 两侧循环和回放分别反传，累积后一起更新G／反向网络；随后独立更新D，避免同时保留全部计算图 |
| P/Q输入 | 增加浮点、有限值、范围、坐标和P概率和检查；原版只检查了P/Q尺寸 |
| 解码数值 | 在输出clamp前拒绝NaN/Inf，避免Inf被clamp变成有限值而掩盖故障 |
| 合成条件的批处理 | 原版只读取`tir[0,0]`；改为逐图构建E/P/Q，原TIR梯度保留 |
| 内容对比的批处理 | 原版跨batch取边缘mask并集；改为每图独立选同图位置，不借用另一图的边缘 |
| 颜色损失开关 | 关闭颜色损失时不再强制先验包含无用的loss_support；开启时仍严格检查训练RGB来源 |
| 文件与缓存 | 准备前拒绝同域同split重名stem；加载时拒绝重复输出名及不一致完成数量，避免静默覆盖 |
| V2缓存溯源 | 新增完整P/E/Q计算相关代码和库版本指纹，包括Q计算及RGB类别映射；源码换行CRLF/LF归一化 |

逐样本修复不等于训练命令已经支持可调batch size。当前正式加载器仍一次返回一张图，不能只改一个配置字段就宣称完成批量训练。

V2缓存新增指纹是为了拒绝“P/E/Q算法已变却复用旧缓存”的情况。V1保持旧缓存身份，以便评估旧检查点。V2需新建缓存目录，prepare/train都指定V2配置；不能直接给旧manifest添加新版本标签。

## 5. 增加的诊断与用途

见[训练引擎](../D/unpaired/engine.py)。在原日志周期收集，不额外运行教师：

- `G_total`、`weighted_*`、`color_weight`：查看实际加权目标，避免直接比较不同量纲的原始损失。
- `control/semantic/color_residual_rms`及相对ControlNet比值：查看残差分支是否学出信号、某分支是否过强。默认CFG=1时取最后一次去噪预测，各残差块RMS的均值；不是整轮平均或贡献因果证据。
- `grad_norm_diffusion`、`grad_norm_reverse`：在原有共同裁剪前分别观察梯度，检查反向网络是否主导共同裁剪。本轮未修改裁剪策略或学习率。
- `decoder_saturated_fraction`、`decoder_abs_max`：检查VAE解码后有多少值超出[-1,1]。原clamp保持；没有未经实验就换成直通梯度。
- `rgb_replay_active`：明确当次是否包含回放，避免把回放周期造成的目标变化误读为训练突然变坏。

已有`grad_TIR/E/C_zero`、各适配器梯度及Q覆盖率继续保留。诊断本身不证明融合有效，更不等于结构置信度。

## 7. 仍需真实结果决定的问题

1. **同一个错误P可能经多条路径强化。** P参与E、语义残差、颜色token、语义损失和平滑。Q只能减弱它识别出的不可靠区域，不能发现全部高置信错分。树冠天空化需同时看原P/Q、E、各分支与最终RGB，不能只看蓝色结论就锁定原因。
2. **潜变量尺度会丢细节。** P先聚合到VAE潜变量尺度，再投影到各残差尺度；细腿、车轮、细树叶可能消失。V2仍保留这个结构，先用小目标裁剪检查，再决定是否做高分辨率注入，避免同时改变过多因素。
3. **结构损失偏向保留已有边缘。** 目前主要约束E支持和局部内容，不严格惩罚每一条新增假边；没有实现显式候选补全、来源追踪和结构C，不能保证没有多生目标。
4. **教师前处理存在尺度差异。** 源RGB准备是512/PIL处理，可微语义损失默认256/张量双线性处理；节省计算但不是完全一致的教师测量。先检查两种尺度的P差异与损失覆盖，再决定是否统一尺度。
5. **循环目标与随机生成可能冲突。** 当前两侧循环都要求重建，但正向仍有加噪随机性；需要固定seed预览，同时检查多个seed下几何是否稳定。不能只挑一张好结果。
6. **训练开销有明确来源。** 每更新两条扩散路径、反向网络／D、生成图RGB教师，以及合成TIR上重算FMB／翻转语义；后者默认CPU。不能缓存随参数变化的fake TIR条件来假装等价提速。GPU前端或批量训练应单独测时间与显存。
7. **泛化仍未证明。** 核心修改没有硬编码FLIR图号／框／坐标，但仍使用道路领域教师、固定街景prompt及训练RGB颜色分布，不能因此称为跨域通用。需独立场景／数据及无人车场景检查。

## 8. Windows结果回来后的最小验证顺序

先完成并保存当前V1的run配置、完整检查点和固定验证图，再确定预算。V2沿用相同划分、初始化、种子、更新数、E、学习率和九项权重；仅改变显式策略：

| 对照 | fusion_policy | chroma_smooth_policy | 要回答的问题 |
|---|---|---|---|
| 原V1 | legacy | legacy | 当前基准 |
| 只改融合 | quality_masked | legacy | 门控位置是否减少错误语义扩散，是否伤弱小目标 |
| 只改平滑 | legacy | quality_soft | 色度正则是否更少跨错分区域抹色 |
| 两者组合 | quality_masked | quality_soft | 组合是否有额外收益或相互抵消 |

后面三组使用`D_unpaired_v2`签名。不要用原V1的`--resume`套入新源码／新配置；当前严格的代码身份检查也会拒绝恢复。V2先从同一RGB预热检查点或相同预训练起点重新开run，不能直接拿V1正式部分权重当作V2续训。本轮没有自动启动这些实验。

关闭`use_semantic`或`use_color`只关闭独立残差；E和相关损失可能仍在使用同一先验。若要声称“完全无语义／无颜色”消融，需同时明确全部信息入口。上述四组不是这种完全移除消融。

优先看人车数量／位置、腿和轮胎等边界、小目标与无人车图、树冠天空交界及颜色跨区域传播；再按统一协议比较FID/KID和结构指标。仅凭45项测试通过、Q覆盖率、残差范数或单张视觉改善，都不能宣称性能最优或避免过拟合。

# 固定候选的新增补边重要性：实现与泛化检查

日期：2026-10-29。本轮只实现上一阶段的①：固定已有候选、路径、冲突决策和结构可靠性C，只重加权新增部分。不实现目标归属搜索或弱端点召回，不改变原clarity、不更换diffusion条件，也不重新训练生成器。

## 1. 要解决的问题

方向连续、梯度稳定的道路纹理可以是真边，但对人车结构任务不一定重要。不能因此把它的C改成低值。本轮单独给新增路径确定R，并比较同一候选在相同新增总强度下的分配差异。没有新增学习参数；固定规则仍可能存在人为设计偏差，不能由“没有训练”推断不会过拟合。

实现为`models/completion_importance.py`，函数入口为`prioritize_completion`；输入原E、原路径记录、归一化结构重要性、纹理代理，以及可选P/Q。不接收图号、文件名、框、图像上下位置、目标数量或数据集名称。未配置语义时使用相同结构回退。

## 2. 统一规则与职责

对一条既有路径γ，结构回退为路径上`R_structure*(1-clutter)`的平均值，记作r_s。复用原C2c结构／纹理计算，并将其[0.18,0.85]映射到[0,1]；不重新拟合这套规则。原方法像素尺度及模型偏差仍可能限制跨分辨率／跨场景效果。

在路径中心及法线两侧采样语义；偏移为局部缺口长度的0.35倍，至少1像素，越出图像的采样不提供语义可靠性。这样不只读取被Q边界侵蚀置零的中心线。

- t：中心／两侧可配置任务类别的Q加权软响应。默认覆盖person、car、truck、bus、motorcycle、bicycle、lamp、sign、pole，未给某一类别独立阈值或形状模板。
- b：两侧类别分布的半L1差异，乘两侧Q的较小值。它与具体类别无关，可以支持建筑、树冠、路缘等非任务类别的区域边界。均匀不确定响应不凭自身产生边界。
- q：中心／两侧最大Q沿路径的平均值。原Q是单视图缓存的启发式可靠性，未额外进行翻转推理，不是独立正确概率。

路径重要性与强度增益为：

\[
R_\gamma=\operatorname{clip}\bigl(\max[\max(t,b)+(1-q)r_s,\;0.5r_s],0,1\bigr),
\qquad a_\gamma=0.25+0.75R_\gamma.
\]

语义缺失／Q为零时精确回退到r_s。高Q但错误的背景判断仍有0.5r_s结构备份；这不能纠正分割错误，但避免仅因错误类别完全取消结构支持。道路、植被不作硬清零；主边界可以通过b保留，真实但不重要的密集纹理由R调节，C保持原值。

将新增路径原幅值乘a_γ，仍使用原C、同一路径和同一软编码。所有原字段保持，不改变候选排序、端点配对、接纳／拒绝决策或数量。满足逐像素`E_obs ≤ E_priority ≤ E_old_reliable`。增益最低0.25是对路径幅值而言；与原E取max后，真正新增强度的保留比例可能低于25%，因为一些弱增量被原E覆盖。

这一步不新增原本没有提出的脚部／轮胎候选，也不保证已补线属于同一物体。目标归属检查与弱端点召回仍须另行实现／对照，不能将本轮称为完整人车补全。

## 3. 同均值对照

四组旧预览完整保留。本轮新预览比较：旧可靠性补边、同均值整体衰减、重要性重加权，并显示原TIR与路径增益。

\[
\Delta E_0=E_{old}-E_{obs},\quad\Delta E_R=E_{priority}-E_{obs},
\quad k=\frac{\sum\Delta E_R}{\sum\Delta E_0},
\quad E_{uniform}=E_{obs}+k\Delta E_0.
\]

k只用于描述性对照，不用于生成R，也不作为运行时调参。匹配的是取max后的真正新增强度，不缩放原E。没有新增时定义k=1。路径位置本来就保持不变，等亮度中心线图应相同，比较时需看实际浮点条件／增量，不能把更暗当作更正确。

## 4. 防止针对开发图写规则的措施

- 只有一套固定参数，在读取首张结果前写入`frozen_plan.json`，无阈值扫描、训练或按结果回调参数。计划标识为规范化JSON的SHA256；验证记录另保存计划文件本身的SHA256。
- 使用全部40张既有开发图／90个裁剪，按24个视频分别导出，类别统计也完整保留，不只选择改善的图号或类别。框仅用于事后定位统计，未进入算法。
- 现有40图覆盖FLIR训练侧全部24个视频，因此同视频新增帧或当前逐视频表不能充当独立泛化验证。未读取正式testB，也不按test选择规则。
- 单元检查覆盖全部配置任务类别、无目标、无语义／Q为零、语义错误、可信非任务边界、类别通道重排、自定义类别体系、旋转、翻倍尺寸、空候选、坏输入及真实导出。
- 从MSRS的`train/ir`和LLVIP的`infrared/train`按固定seed42各取6张，不读取它们的test或标注。最多将长边缩到360，保持比例、不裁剪；不静默处理16位热数据。

本地未找到独立FMB权重，外部样本没有执行语义模型。外部原E采用均匀未知类别响应构造，新增R调用无语义回退。它们是**跨数据来源的结构回退压力测试**，不能证明完整语义链、完整模型或真实补线精度的跨数据集泛化。完整外部验证仍需固定算法后补齐同配方的分割推理及独立边界评价。

当前C2c结构统计、冻结语义模型和任务类别集合都有自身偏差；未来相机、热噪声、类别分布或目标尺度改变时仍可能失效。结构备份、软权重和无目标检查降低部分风险，不构成泛化保证。

## 5. 实际运行结果与限制

- 40张FLIR开发图的1851条原可靠性接纳路径全部保持，旧E及旧补边基线逐像素一致；C分数与原有所有候选字段均保持。
- 新增18项检查通过；共享检查148项、D检查73项，共221项通过。D原有已验证训练源码未更改。
- 同参数完成52张图：40张FLIR开发图、6张MSRS、6张LLVIP；90个原定位裁剪全部导出。所有对照的同均值误差最大约8.4e-12。
- FLIR新增总强度保留约39.7%。按同一份语义软响应划分，重要性版相对于同均值对照的新增强度比值：person约1.60、car约1.69、road约0.72、vegetation约0.65、building约0.62。完整15类结果在CSV中，lamp/sign/pole等并非都提高。
- 上述类别代理与生成R使用同一语义模型，存在自相关，类别面积及分割错误也会影响统计。它只验证强度分配发生了预期变化，不能报告为真实人车补线正确率／召回率，不能证明错误语义已被修正。
- 已查看31号新增增量及LLVIP示例，整体变化较细微，因为原E保持；重要性不能填补原来没有候选的目标。真实道路误连、目标归属、弱脚部漏补及生成效果仍需独立审查。

# 学习式软轮廓：边界监督 / 边界监督 + 局部对比学习

> 此文描述保留的监督式实验分支。当前已按“FLIR 无边界标注、一次联合训练”的要求新增 JR0/JR1；请使用 [无标签轮廓联合训练两版](无标签轮廓联合训练两版.md) 中的入口和命令。

## 1. 当前做到哪里

已写好两版共用的网络、训练、冻结推理、固定样本预览和合成测试。尚未使用真实边界标注训练，不能判断哪版更好。现有 C2b/C2c 代码、运行命令和实验名称没有改动。

两版是独立的轮廓提取实验分支，不占用之后的置信度通道。CycleGAN 的训练入口尚未接入这个新提取器；目前提供了与现有 `edge_override` 相容的冻结推理接口。

| 对照 | 训练信号 | 输出 | 用途 |
| --- | --- | --- | --- |
| `supervised` | 已标区域的边界分类损失 | 单通道连续边界分数 | 判断可学习网络本身是否优于固定 Canny |
| `contrastive` | 同一分类损失 + 局部对比损失 | 同样的连续边界分数 | 判断额外的对比学习是否有帮助 |

## 2. 网络与数据流

网络位于 `scripts/contour_learning/model.py`，是一个小型编码器—解码器：

```text
TIR [N,1,H,W]，归一化到 [-1,1]
  → 原分辨率特征（24 通道）
  → 1/2 分辨率特征（48 通道）
  → 1/4 分辨率特征（96 通道）
  → 两级解码，拼接对应尺度的跳接特征
  → 原分辨率特征 → 1×1 边界头 → sigmoid → S∈[0,1]
```

保留原分辨率分支，只下采样两次；解码使用最近邻上采样加卷积，训练用裁剪而非先缩小整张图，减少小目标信息被输入处理丢掉的风险。这些设计提供学习细小结构的路径，不保证恢复红外图中不可辨认的轮廓。

`S` 是学习得到的边界分数。它不是下一阶段的“此边缘是否可靠”的置信度，也未经过概率校准。

两版都实例化相同的投影头，保证参数结构、初始化一致；监督版不使用该头，对比版才将它连接到额外的损失。推理仅用边界头。

## 3. 两版如何训练

**第一版：边界监督。** 输入两种增强视图，两张预测都与各自正确变换后的标注比较；只在有明确标注的像素上计算正负类平衡的 BCE。未知区域不作为背景。正类、负类分别求平均再平均，避免大量背景淹没细边界，但仍需检查过多边缘和填满目标内部的问题。

**第二版：加局部对比。** 使用完全相同的视图和监督。在特征层做对比：

1. 水平翻转、90°旋转和轻微灰度扰动得到两种视图。
2. 将特征逆变换回原坐标，精确找到同一像素。90°旋转不需要插值。
3. 已标边界像素作为锚点，同一像素在另一视图中的特征作为正样本。
4. 明确标为非边界且超过邻域排除半径的像素作为负样本。
5. 其他边界和未知区域不当成负样本，两个方向都反向传播。

```text
监督版：L = L_boundary
对比版：L = L_boundary + 0.1 × L_local_contrast
```

`0.1` 是初始实验设置，没有验证为最优。这里实现的是局部特征对比，没有实现论文里的拓扑图对比。它促使边界与已知非边界的特征更容易区分，不直接约束闭合性、人体形状或语义。正负样本依靠标注，不能仅靠一致性来证明是真实轮廓。

每轮记录 `active_anchors` 和 `contrastive_active_batch_fraction`。如果一整轮没有可用对比样本，直接报错；部分批次无可用样本会跳过该批次的对比项，但照常训练边界任务。

## 4. 真实训练需要的标签格式

当前没有真实边界标注，先只运行第 5 节合成检查。

后续 `annotations.csv` 至少包含以下列，路径相对 CSV 所在目录，也可写绝对路径：

```csv
image,edge,split,video_id
../../FLIR_datasets/trainB/实际文件名1.jpg,labels/实际文件名1.png,train,实际视频ID1
../../FLIR_datasets/trainB/实际文件名2.jpg,labels/实际文件名2.png,val,实际视频ID2
```

标签必须是与处理后的红外图同尺寸、同坐标的 **8 位灰度 PNG**：

- `255`：明确的边界像素。
- `0`：明确的非边界像素，包括已审查的目标内部和背景区域。
- `128`：未标、不确定或不想监督的区域，训练与评测忽略。

若只标人、车、建筑物附近，其他未审查区域应填 `128`；不能因为没画线就默认是 `0`。不能用定位框代替目标外边界。标签不得用抗锯齿绘制或有损 JPEG，以免产生非法灰度值。标签宽度、画边界的规则必须先固定，两版一致。

训练/验证按完整视频分开，两个集合都必须有边界和非边界标注。真实实验只允许从原 `trainB` 划出训练/验证，检查文件名、视频 ID 和图像内容哈希；拒绝 `testB` 混入。数据和标签哈希、初始权重哈希都会存入检查点。

## 6. 有标注后的真实训练命令

**目前先不执行。** 下面假定标签 CSV 已准备好。两版的网络、初始权重、裁剪、增强、种子、训练预算一致，仅 `--variant` 和输出名称不同。

```powershell
python scripts/train_learned_contours.py `
  --annotations "$thermalRoot\annotations\contours\annotations.csv" `
  --protocol "$thermalRoot\FLIR_protocol_v2\manifest.csv" `
  --processed-dir "$thermalRoot\FLIR_datasets\trainB" `
  --variant supervised `
  --output-dir "$thermalRoot\runs\contour_models\boundary_supervised_40_40" `
  --n-epochs 40 `
  --n-epochs-decay 40 `
  --crop-size 256 `
  --batch-size 1 `
  --seed 2026 `
  --contrastive-weight 0.1 `
  --device cuda

python scripts/train_learned_contours.py `
  --annotations "$thermalRoot\annotations\contours\annotations.csv" `
  --protocol "$thermalRoot\FLIR_protocol_v2\manifest.csv" `
  --processed-dir "$thermalRoot\FLIR_datasets\trainB" `
  --variant contrastive `
  --output-dir "$thermalRoot\runs\contour_models\boundary_contrastive_40_40" `
  --n-epochs 40 `
  --n-epochs-decay 40 `
  --crop-size 256 `
  --batch-size 1 `
  --seed 2026 `
  --contrastive-weight 0.1 `
  --device cuda
```

这是**轮廓提取器额外的预训练预算**：40 恒定 + 40 衰减，共 80 轮。不是用它替代 CycleGAN 原来的 80 轮；论文中需报告额外的标签和计算成本。正式 CycleGAN 的数据、80 轮预算和统一评测仍按原协议固定。

每轮保存 `latest.pt`，同样按验证集边界 BCE 最低选择 `best.pt`，每 5 轮保存编号权重。`history.json` 包含边界损失、对比损失、可用锚点和验证指标。验证阈值固定 `0.5`，边界 Precision/Recall/F1 容忍 1 像素偏移；指标只反映已标区域，不等于整张图或所有重要目标的正确率。`edge_fraction_at_0.5` 辅助发现边界泛滥，不能单独判断质量。

断电续训：在相同命令末尾加以下参数，并使用原输出目录；原 `--device cuda` 行末需补上反引号以连接下一行：

```powershell
  --resume "$thermalRoot\runs\contour_models\boundary_contrastive_40_40\latest.pt"
```

恢复模型、优化器和历史，按保存轮的下一轮继续；中断轮内的未保存进度会重跑。CPU 合成测试验证了恢复结果一致，尚未测试服务器 CUDA 环境的一致性。

## 8. 后续怎样交给 GAN

冻结接口示意（运行环境需能导入 `scripts/contour_learning`）：

```python
from contour_learning.model import FrozenContourExtractor

extractor = FrozenContourExtractor("best.pt", device="cuda")
# tir 必须是 loader 已完成 crop/flip 后的 [-1,1] 单通道张量。
soft_edge = extractor(tir)  # [N,1,H,W], no_grad
rgb = conditioned_generator(tir, edge_override=soft_edge)
```

现有 `ConditionedGenerator(..., fusion_mode="direct")` 的覆盖接口会拼接 `[TIR, soft_edge, 0]`，第三通道仍为零。此处展示接口；还未把它接入 `conditioned_cycle_gan_model.py` 的所有正向、重建与测试路径，不能直接修改一个 forward 就视为完成正式实验。

轮廓网络有明确监督，可以验证它是否学到了边界。但 GAN 仍可能忽略该通道。接入后仍需比较真实轮廓、置零轮廓、错位轮廓对生成结果与结构指标的影响。存在非零梯度只证明传递路径正常，不证明模型实际依赖轮廓。

# C2c 显著性空间权重独立审查

这一步不改模型、不训练 GAN、不使用 JR 权重，只检查当前 C2c 的空间权重 R 是否有合理的选择作用。

## 单一变量

两组完全共享细／粗尺度 Canny 候选、纹理抑制 D、背景增益 0.5 和细边底线 0.25：

- 当前 C2c：使用空间变化的 `R(x,y)`。
- 常数对照：每个位置使用该完整图像的 `mean(R)`。

候选使用高阈值 0.12/0.16/0.20、低高比 0.5、尺度 0.7/1.0/1.6、软化宽度 1。审查中的公式副本逐像素核对正式 `soft_saliency` 输出；不进入训练代码。

注意：共享的 D 仍包含空间纹理信息，因此这只是 **R 的独立消融**，不是整个 C2c 的消融。平均 R 相同也不保证最终图像同亮度，因为 R 与候选轮廓有空间相关性且存在底线裁剪。

## 抽样与范围

默认 seed42，从 trainB 按视频均衡抽取 24 张常规图，再从尚未选中的小目标图中抽取 8 张挑战图。小目标条件及固定重点目标选择复用已有 `review_contour_candidates.py`，只依赖标注框大小，不依据轮廓效果挑样。

已有 FLIR 标注框只用于抽样和定位放大区域，绝不作为轮廓真值、目标掩膜或训练监督。框内可能有背景，框外可能有重要建筑／道路结构。常规与挑战组分开统计。这是开发审查，不是独立泛化测试；不要根据 testB 调参。

## 运行

在现有 PowerShell Python 环境中执行，按本机位置修改路径：

```powershell
$thermalRoot = "E:\上海大学\项目\thermal\Thermal_on_Mac"
Set-Location $thermalRoot

python scripts\audit_c2_importance.py `
  --output-dir "$thermalRoot\runs\edge_audit\c2c_importance_ablation_20261012_seed42" `
  --sample-count 24 `
  --challenge-count 8 `
  --seed 42 `
  --geometry full
```

工具只用 CPU，拒绝覆盖任何已有输出目录。重做 256 中心裁剪对照时，使用新目录和 `--geometry center_crop_256`，并传入第一次输出的 `--selection-json`，保持同一批图。中心裁剪只是训练尺寸的诊断代理，不等于随机裁剪的整个训练分布。

## 查看

- `index.html`：固定强度的全图、R／D／差异图及重点目标放大图。
- `maps/*.npz`：原始浮点候选、R、D、两组输出及底线前结果。
- `selection.json`、`audit_manifest.json`：固定样本、参数和源文件／代码哈希。
- `samples.csv`、`targets.csv`、`summary.json`：响应变化统计，不是准确率或边界 F1。

上行为 [0,1] 灰度，下行为相同强度的红色叠加；所有轮廓共享显示范围，不逐图拉伸。差异图统一 ×4：红色为空间权重增强的位置，蓝色为减弱的位置；颜色不表示正确性。

审查顺序：先确认原图可见边界，再区分候选缺边、R 误抑制目标、最终融合底线保留杂纹。评价可见边界，不把遮挡处当漏检，也不把响应更亮当作准确率更高。只有在目标保留与非关键杂纹抑制之间出现稳定改善，才考虑下一步修改特征；本审查不证明生成 RGB 改善。

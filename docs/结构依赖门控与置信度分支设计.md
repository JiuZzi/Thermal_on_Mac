# 结构依赖门控与置信度分支：设计建议

日期：2026-10-30。状态：可学习分支尚未实现或训练；本轮已落实第5节的第一步，新增独立[固定权重抑制诊断](结构依赖门控固定权重诊断.md)。其中G由规则生成，不称为学得置信度。用户决定补边分支先保留当前结果，转向研究如何主动减弱不必要的边对着色的影响。

## 1. 输出应该表示什么

道路裂纹、树叶内部纹路可能是真实而稳定的红外边。用户当前要解决的是“这条边是否应当强约束可见光生成”，不只是“这条边是否真实”。建议把本轮输出定义为结构依赖权重G，避免把它直接叫作经过校准的正确概率。

- R：先验任务重要性，已有结构／语义规则提供“哪里值得重视”的参考。
- G：根据生成任务学习，当前生成对这处轮廓应依赖多少。
- C_add：补全候选是否可信，继续留在独立补边分支。
- Q：语义可靠度代理，不能代替G或C_add。

树冠外缘、树干、路沿、车道与车辆边界可能需要保留；树冠内部细密纹理、路面热斑未必适合逐条强制复制。边的长度、类别和梯度强度均不能单独决定去留，不把道路／植被整类清零。

“这些边导致串色”仍是假设。语义高置信错分、颜色先验错误、生成器本身也能导致同样现象，需保持这些因素固定做干预对照。

## 2. 当前D中与它相关的入口

`D/unpaired/model.py`目前明确使用`[TIR,E,0]`，`confidence=False`，校验拒绝非零第三通道。

- E与TIR一起进入ControlNet的条件编码。
- 相同输入还进入SourceAdapter并影响初始潜变量。
- `D/unpaired/engine.py`将原E传给结构保持、内容采样和色度平滑。
- `edge_preservation`按E要求生成RGB保留局部梯度响应和方向，当前不区分外轮廓与内部纹理。
- `chroma_smoothness`使用`exp(-5*max(E_i,E_j))`，因此E强的地方降低颜色平滑。细密纹理较强时，可能切碎同一区域的颜色约束，但这需要实验确认。

因此，门控不能只在某个输入通道出现；需要明确它控制了哪些条件路径，以及损失是否仍在要求保留被减弱的纹理。也不能将包含TIR和语义／颜色的混合残差整体乘G，顺带关闭其他信息。

## 3. 推荐的第一版结构

输入复用已有TIR、E、P、Q，并补充便宜的局部边缘密度／多尺度梯度统计；已有R可作为参考特征，但不把结果写成`E*R*G`再次机械重复抑制。语义仅作上下文，不作为绝对边界真值。

采用小型卷积分支，例如16通道的3层3×3卷积、不同膨胀率及1×1输出，Sigmoid产生与E同分辨率的G。按具体输入通道计算约几千到一万网络参数，实施时应实际统计参数、激活显存和时间；不新增SAM、分割教师或第二套扩散网络。像素级输出保留细目标，避免只在H/8潜变量尺度上决定所有门控。

初始G接近全开，训练初期逐渐允许抑制；避免随机初始化直接抹掉结构。G在已有生成目标的反馈下学习，不用“道路=0、行人=1”硬标签替代学习。

第一版的明确使用方式：

\[
G=\sigma(g_\theta(T,E,P,Q,\text{local context})),\qquad E_{use}=E\odot G.
\]

ControlNet和SourceAdapter都使用`[TIR,E_use,0]`；VAE仍编码原始TIR的三通道复制。P/Q与学习式颜色分支仍按既有独立策略使用。G单独输出诊断，先通过乘法真正改变E的贡献，是否再把G作为第三通道信息应另列实验。

如果后续发现输入已压弱但卷积邻域仍传播干扰，再单独研究明确分离边缘贡献的特征门控；不在第一版复制整个骨干。任意门控都不保证最终RGB不出现同类纹理，因为TIR内容、先验与生成器仍会提供信息。

## 4. 训练信号和防退化

### 4.1 无配对约束保持正确

门控与现有适配器共同学习，保留既有预训练主干冻结策略。TIR/RGB仍独立采样，不用随机配对RGB监督当前TIR的像素颜色。

真实TIR、合成TIR循环和RGB自回放要使用一致的门控定义。RGB自回放仍以同一张真实RGB构造去噪目标。合成TIR的辅助特征可detach，原TIR到VAE／内容路径的梯度仍保留；不把随着G参数变化的输出当成静态语义缓存。

### 4.2 门控与结构损失不能互相抵消

如果输入使用E_use，结构损失却继续无差别强制保留全部E，任务会冲突；如果直接让可训练G乘损失，则G又可能通过关闭权重降低损失。

建议把G用于损失权重时停止该权重的梯度，并保留一组与G无关的保真依据。例如从源观测中保守选出的跨区域结构边界，固定为B_anchor；未知处不当作负例，也不将所有强边都当正例。

一种待消融形式为：

\[
W_{edge}=E\odot\max(\operatorname{stopgrad}(G),B_{anchor}),\quad
L_{edge}=\frac{\sum W_{edge}\ell_{edge}}{\sum E+\epsilon}.
\]

方向项使用对应的固定E／方向有效掩码分母。这样分母不会随门控一起缩小，保真的参照也不由门控自己关闭。G=1时仍可对齐原权重定义。B_anchor来自固定源证据，属于弱参考而非正确性真值；若它依赖P/Q，必须检查高置信错分传播，不能宣称独立保证。

这只能限制部分退化，不能保证门控一定有用。保留原始TIR内容／循环约束，记录G是否全开、全关或常数，并与相应基线比较。若关闭E整体就更好，应接受当前轮廓分支可能冗余，而不是硬规定每图必须保留某个百分比。

仅用R监督G可能只是把旧R复制一遍；仅用一致性监督又可能保留稳定叶纹。源证据适合作弱先验／初始化，主要作用仍需生成反馈和独立验证支持。

### 4.3 颜色平滑要保护真正的区域边界

被减弱的纹理不应继续一律阻断类内色度平滑。可以用`E*max(stopgrad(G),B_anchor)`替代这一用途中的边界屏障，同时继续考虑软语义相似度及Q。

边缘减弱不等于让整幅图任意抹色。跨可靠语义边界或可信几何边界仍应允许色度变化；Q低或语义不确定处减少强制平滑。高Q的树冠／天空错分仍可能绕过这些规则，需独立检查语义／颜色链。

内容采样也要审查细纹是否占据大部分采样位置。若调整为可靠粗结构与均匀位置的混合采样，需另设对照，不能把该改变的收益都归因于G。第一轮不同时扫骨干、先验与所有损失系数。

## 5. 最小验证顺序

1. **先做因果诊断。** 有可用D权重时固定权重、采样种子、步数和P/Q／颜色条件，比较原E、全图等量减弱、按空间选择减弱细密纹理。此步骤检验既有模型的条件敏感性，不代替重新训练验证，也不保证门控分布外输入有效。
2. **最小学习版本。** 固定同一轮廓E，比较无门控、同容量恒定门控与小型可学习G；补边暂不混入。规则生成的掩码仅作诊断／弱参考，不作为真实置信度标签。
3. **损失配合单独比较。** 输入门控、损失调整、两者结合分开归因；若增加共同的锚点损失或采样策略，也给无门控基线使用相同项。
4. **同一权重下的干预。** G=1、G=0、同平均强度的常数G、空间打乱G与正常G。它们检验空间选择作用，不能与不同训练run混成一个结论。
5. **验证质量与代价。** 看路面／树冠内部色度波动、区域间串色、颜色是否仅变灰、人车数量／位置、边界位移、小目标及无人车场景；再按固定协议报告FID/KID等。边少或G更黑不算成功。

划分按视频／场景隔离，外部数据使用同一设置。细密纹理区只用于解释行为，不按某张FLIR图号、固定位置、面积或类别手写去边规则。输出每图TIR、原E、G、E_use与RGB，便于复核错误发生在哪一环。

## 6. 相关机制与创新边界

[Yu等，ICCV 2019，Free-Form Image Inpainting With Gated Convolution](https://openaccess.thecvf.com/content_ICCV_2019/html/Yu_Free-Form_Image_Inpainting_With_Gated_Convolution_ICCV_2019_paper.html)已经研究可学习的空间／通道特征选择；本项目借鉴选择信息流的原则，任务及监督不同。

[Liu等，2024，SmartControl](https://arxiv.org/html/2404.06451v1)预测局部控制尺度，缓解粗糙视觉条件与文本的冲突；本项目处理红外观测结构对可见光生成的任务适用性，不能直接照搬其文本冲突标签，也不能声称局部门控本身首次提出。

潜在贡献应落在：热红外结构的依赖选择、与现有重要性／语义可靠度的职责分离、条件路径和损失的一致处理，以及在不损害目标结构的情况下减少着色干扰的实证收益。目前未验证这些结论。

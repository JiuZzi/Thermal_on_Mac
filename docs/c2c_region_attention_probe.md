# 无外部模型的区域重要性小验证

2026-10-12；seed42。用户当前要求：先检验显著性是否按任务分配关注，补边在下一步，暂不考虑 JR0/JR1；尽量不引入其他模型先验。

## 本轮假设与范围

只用红外自身的连通区域和区域/周围差异，能否减少逐点对比增强对细碎纹理的响应，同时保留重要目标和建筑主结构？这是假设，不预设优于原 C2c。

这是独立的固定规则可行性探针，不是已学习的任务显著性模型。不训练、不接入训练 CLI、不修改正式模型、原始图像、权重或旧预览；不使用外部模型、检测器、预训练权重。已有框只用于取样、定位和统计，不传入重要性生成。

## 一次性固定的设计

实现 `scripts/region_attention_probe.py`：

1. Felzenszwalb 灰度图分割得到连通区域：scale=100、sigma=0.8、min_size=20。它是传统图分割，不需要训练权重，也不等价于语义/实例分割。
2. 每个区域计算中位灰度，与区域外 8 像素邻域的中位灰度比较。分数为绝对差 /（绝对差 + 区域内平均绝对偏差 + 外邻域平均绝对偏差 + 0.03）。亮、暗区域同等处理。没有对象形状、中心位置、热目标优先或外部类别先验。
3. 分数图高斯平滑 sigma=1，映射到 [0.18,0.85]，与原 R 各占一半。允许 R 上升或下降，保留原结构分支作为缓冲。固定权重不是最优值，不根据本轮标注结果调参。
4. 原 F/C/D、融合公式、0.25F 底线全部固定。区域掩膜只调节 R，绝不作为新的边缘输入；所以不能单凭亮区域把人填成白色轮廓。

区域中位值和分数用于解释，不是置信度。局部热对比不等于任务重要性；纹理也可能组成独立区域，小人也可能被区域合并。保留这些失败，不继续为少数图扫参数。

## 比较与复核

- 重用旧 seed42 的 32 张 trainB 开发样本（24 普通 + 8 小目标挑战），逐图校验图像 SHA 和旧 F/C/D/R/E。
- 额外优先选取旧 24 个视频以外的 8 张 trainB、视频均衡、seed42 样本作为未用于本轮设计的扩展审查；若不存在新视频则明确记录范围，不能称独立视频验证。
- 实际检查发现旧样本已覆盖 trainB 的所有视频。因此扩展运行显式使用 `--allow-same-video-extras`，补充 8 张未出现在旧 32 张里的同视频新帧；算法及参数未改，不构成跨视频泛化证据。
- 比较原 C2c、此前 region_recall、区域探针，以及与区域探针**整图均值相同**的原 C2c 统一缩放对照。允许全局变暗，所有裁剪复用整图缩放，不重新归一化。
- 重要性 R 与轮廓 E 分开显示，固定 [0,1]；不能把更暗当作少纹理成功，也不能把更亮当作目标保留成功。
- 对人/车等已标注框内的候选像素和相邻框外候选像素报告关注差异；邻域排除所有已标注目标框。它们是混合区域，框不是真实轮廓标签，框外也可能有有用结构，指标不是准确率。
- 第 02 张复用此前的道路、远景、建筑混合窗口，不让这些窗口进入生成算法。人工查看完整场景与固定人物裁剪。
- 本轮不改参数反复挑图。若削弱纹理的同时也削弱小目标，或只得到一般视觉对比差异，则结论是尚未实现任务选择性，不启动正式训练。

## 与后续置信度的接口

本轮只审查 R（关注分配）。E 仍是轮廓响应，第三通道仍留给 C；没有以区域分数、边缘亮度或分割一致性冒充正确性概率。未来 C 用于可靠性判断，不能代替 R 的重要/不重要取舍。

分割接口参考：[scikit-image 官方文档](https://scikit-image.org/docs/0.25.x/api/skimage.segmentation.html#skimage.segmentation.felzenszwalb)。本探针公式是项目内设计，非该库自带任务显著性算法。

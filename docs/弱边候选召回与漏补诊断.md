# 弱边候选召回与漏补环节诊断

实验建立：2026-10-29；结果整理：2026-10-30。当前是独立的候选生成实验，尚未接入D训练。**机制检查通过，但真实开发图的人车缺边改善很小，不能把本轮说成已经解决脚部／轮胎漏边。**

## 1. 实验问题与固定对照

上一轮只对相同1851条FLIR接纳路径调整新增重要性R，不生成新路径。当前要区分三件事：候选根本不存在、候选被几何／C筛掉、候选通过但实际强度很低。先解决候选覆盖，不因视觉上补得少而整体放宽可靠性阈值。

本轮固定原始TIR、原E、已有候选、已有几何配对、旧C及旧R；只追加一类新候选。原有被C拒绝的几何连接也继续占用原端点，未混入“拒绝后重配对”的变化。因此这是保守的增量对照，不能据其判断重新匹配的潜在收益。

## 2. 新候选如何产生

入口是`models/completion_recall.py::recall_completion`。它只接收TIR、原观察轮廓、原脊线和原补边记录；没有类别、框、文件名、图号、图像上下位置或生成RGB输入。

1. 复用旧补边的三尺度、噪声归一化梯度证据。其幅值按梯度自身、噪声代理与`1/255`底线归一化，不按每张图最大值／分位数拉伸。
2. 沿梯度法向作非极大值保留与细化，得到弱脊线；平均归一化支持至少为原`support_threshold=0.25`，至少2/3尺度的梯度幅值达到同一支持阈值。这里的数值仍是工程证据代理，不是正确概率。
3. 从**未被旧几何占用的原端点**出发，沿外向切线锥作确定性的短距离束搜索。新像素必须有弱脊线与方向相容的梯度支持，不跨原脊线／旧几何，不穿对角交叉。没有连续证据就停止。
4. 复用旧65度方向约束、转弯代价、1.6倍绕行限制及短边0.035的局部预算。这里限制的是新延伸的弧长；360×288时至多10.08像素，比按端点直线距离限制更保守。最少3个新增内点，末端仍作为不绘制的观测锚点。
5. 允许连接到合格的未占用旧端点，也允许终止于有测量证据的弱片段。后者只表示可见弱轮廓的延伸，不推断遮挡后的隐藏人体或轮胎形状。

束宽4，每端点最多256个展开状态，最多4096个原端点可进行延伸；预算、分支剪枝和停止原因全部记录。近邻网格终点／同一路径前缀去重，保留真正不同的分支供原C检查竞争歧义。真实开发预览没有触发端点数量预算或每端点状态预算；束宽仍会限制候选完整性。

新末端的方向质量由其可见弱片段估计。新路径幅值取原端点E、末端测量支持和路径方向支持均值的最小值，不给弱片段虚构一个强原始E。

## 3. C、R与输出保持什么

C完全使用旧公式与阈值：平均方向支持0.40、覆盖0.25、跨尺度0.20、切线质量0.15，随后按竞争代价间隔衰减；默认评分0.58、覆盖0.45、最长无支持段0.65、间隔0.08。新候选会有自己的测量值和竞争关系，但不改旧候选的任何值。

R复用`prioritize_completion`，仍由任务类别软支持、类别无关区域边界及结构回退计算。R不参与新路径搜索，未用人车类别筛选弱边候选。原候选的R和增益逐条一致。

软编码仍为每路径σ=0.5的高斯后取max。新输出满足：

```
原E ≤ 旧补边+C/R ≤ 追加弱边候选+C/R ≤ 1
```

逐像素保留旧输出是一项实验控制，不代表旧误边被纠正了。旧几何锁定及已有错误仍可能限制新召回；目标归属检查、弱片段独立锚点与重配对还需要分别比较。

## 4. 诊断和独立评价工具

- `baseline_stage_diagnostics.json`：原端点、候选、几何选用、C接纳与拒绝原因。拒绝原因可重叠，数量不能解释为真实缺口召回率。
- `endpoint_diagnostics.csv`：每个旧端点是否被旧几何锁定、锚点观测冲突、无合格弱延伸、已提出候选或预算受限，以及详细停止计数。
- `candidate_statistics.csv`：每条新路径的C、R、幅值、长度、几何／C拒绝原因。
- `target_statistics.csv`：90个既有目标框内的新增中心线与强度。框只作事后定位，框内有新线不代表连接正确。
- `completion_recall_validation_20261029/target_endpoint_diagnostics.csv`：目标框内原始度数1脊点、可用端点和各阶段数量的事后核对。它定位候选限制，不能代替某个真实缺口的标注。
- `annotate_gaps.html`：可直接在原TIR上点击折线，分别标记可见缺口、不应补的负例、无法判断的位置；算法图默认折叠。下载JSON后，使用`--annotations`生成另一个复核目录。标记从不进入算法。

真实缺口标注默认为空，明确不输出自然边界准确率。若提供标注，会保留各阶段1像素容差的连续覆盖，并以覆盖不足一半定位可能的漏补阶段；覆盖邻近不能证明边界归属正确，负例和不确定项分别保留，不混入正例召回。

## 5. 固定控制实验与泛化边界

参数在读取新结果前固定，在输出首张图前写入`frozen_plan.json`，记录全部输入、旧配方、新源码、12个擦除位置与可用性，没有按图号或类别回调阈值。正式testA／testB未用于本轮开发。

在既有开发视频／外部训练样本组中按seed42抽取最多一张图，独立于新算法成败选择无分叉观测链，擦掉6／10／14个中心脊点及1像素邻域，保留原TIR。12组使用同一C/R，测量被隐藏的已观测边是否恢复。这是**受控擦边检查**，并非真实弱边或遮挡标注；其支持通常比自然缺口更完整，结果可能明显乐观。

擦边的“可见覆盖”按实际新增强度≥`1/255`、与被擦原脊线距离≤1像素计算；同时报告候选／几何／C覆盖。仅在被擦区域内评价相对原脊线的局部偏离，区域外新线仍没有真值，不能一律称为误补。不能只报召回而忽略区域外新增。

仍使用全部40张FLIR开发图及全部90个原定位裁剪。这40图已覆盖训练侧24个视频，不能将其称为未见视频测试。另对MSRS和LLVIP训练侧固定各6张做同规则无语义回退检查；本地缺少独立FMB权重，未执行完整外部语义链。没有新的学习参数，但固定规则同样可能有设计偏差，不能保证泛化。

## 6. 本轮客观结果

| 项目 | 结果 | 可以支持的判断 |
|---|---:|---|
| FLIR旧C接纳路径 | 1851条，全部保留 | 旧对照未被改写 |
| FLIR新候选／几何选用／C接纳 | 300／293／266条 | 连续弱证据可以进入候选；不是266个真实缺口 |
| FLIR新中心线 | 1228像素 | 仅位置描述 |
| FLIR实际新增强度 | 16.599，约为旧补边增量310.899的5.34% | 整体变化仍小；不是相对原E的5.34% |
| 90个目标框 | 3框有新中心线，2框有≥1/255的新强度像素 | 真实人车覆盖很有限，不能宣布质量提升 |
| 11／18／31的原目标框 | 都没有新接纳中心线 | 当前策略尚未改善这些重点案例 |
| 12组辅助擦边可见覆盖均值 | 29.7% → 77.9% | 可恢复部分被人工隐藏的观测边，不是自然缺口召回率 |
| MSRS／LLVIP新C接纳 | 87／57条 | 外部无语义回退可运行，未证明补边正确或完整泛化 |
| 检查 | 新增24项；共享172项＋D73项，共245项通过 | 约束、回归和导出检查通过，不保证任意场景无bug |

事后端点核对：90框内共有2246个可用源端点，其中463个被旧几何锁定、1776个没有提出合格弱延伸、2个锚点冲突、5个提出候选。框可能重叠，统计是框内定位计数，不是全图唯一端点数量或真实缺口分母。

11_O01大行人框内有25个可用端点：5个旧几何锁定、20个无合格弱延伸；18_O09小行人框内没有可用端点。新路径一旦提出，大部分能通过C，当前人车问题主要仍在端点／弱候选覆盖，而不是仅靠继续降低C就能解决。

已目视核对11大行人、18极小行人和31全图定位。**本轮保留为受控实验，不将新条件直接设为正式训练默认。** 后续先对自然缺口建立可见性和边界归属复核，区分无锚点、脊线间断、交叉占用与真无观测支持，再分别比较弱片段锚点、允许短小观测间断的候选或拒绝后重配对。不能为获得更密的图而同时放松全部限制。

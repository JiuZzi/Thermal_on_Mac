# 片段补全、固定C重匹配和幅值编码对照

日期：2026-10-30。当前是独立开发预览，不改变D默认条件或正在运行的训练。真实目标框的新线覆盖增加，但辅助擦边未超过上一轮，尚不能判定整体最优。三个变化分别比较，不能将新候选增多、图像变亮或测试通过直接解释为真实补线精度提高。[查看最终v3完整对照](../runs/edge_audit/fragment_completion_seed42_v3/index.html)。

## 1. 本轮要检验的变化

此前连续弱脊线追踪依赖原端点，每个新增像素还必须已有合格NMS响应；缺口本身没有连续脊线时，往往无法提出候选。本轮改为由两段测量片段约束一个短连接，候选内部允许观测间断，随后仍交给旧C判断。

| 对照 | 改变 | 固定 |
|---|---|---|
| 旧C/R基线 | 无新变化 | 原始E、旧候选／C／R |
| 上轮弱边追踪 | 已完成的连续弱脊线延伸 | 原有条件与上轮浮点输出 |
| 片段候选，继承E幅值 | 新片段锚点与片段间路径 | 旧几何锁定、C公式／阈值、R、软编码 |
| 仅固定C重匹配 | 释放旧C拒绝连接占用的位置，尝试原池备选 | 候选池、路径、C数值、R与幅值 |
| 相同片段路径的观测幅值探针 | 只将新路径幅值来源由加权E换为原TIR片段支持 | 同一批新路径、几何决策、C、R |

片段组与重匹配组没有合并。主图比较旧基线、上轮弱边追踪、片段组；另外两组单独折叠展示。观测幅值探针可检查重复抑制，但更亮可能同时放大误连，不预设它最好。

## 2. 片段锚点与局部路径

实现：`pytorch-CycleGAN-and-pix2pix/models/fragment_completion.py`。

1. 分别处理原观察脊线图与原TIR的噪声归一化弱梯度脊线图，避免直接合并后将交叉处的可用分支掩盖。弱图使用旧支持阈值0.25及至少2/3尺度支持，不按每张图分位数拉伸。
2. 建立8邻域图；若对角连接可由已有正交角连接替代，则去除多余对角，避免将普通拐角误判成三岔口。按真实图结构在端部／分叉处分解片段；孤立闭环不人为制造锚点。
3. 长度至少为短边`3/288`、且至少3点的片段，沿短边0.018的局部窗口用PCA估计外向切线，方向质量至少0.65。原观察片段需要旧E支撑；独立弱片段可以不依赖旧E，但需要原TIR方向证据。分叉处每条分支可提供自己的方向假设。
4. 相近且同方向的观察／弱图锚点去重。被旧几何占用的坐标继续保护，不能通过增加新ID绕过旧锁定。
5. 两片段端点距离不超过短边0.035（360×288时10.08像素），方向偏差不超过65度；先过滤方向不相容者，再保留每个锚点最多4个兼容邻点。它仍是局部近邻候选，不是全图所有片段对或全局最优配对。
6. 沿两侧法线采样平滑TIR的区域均值，按路径行进方向对齐左右两侧；将端部两侧差异归一化为[0,1]的区域不相容代价，权重0.5。它仅调整优先级／代价，不硬判属于同一物体，也不要求特定类别或固定热极性。
7. 复用原`(y,x,方向)`A*：长度、方向相容的TIR支持与转弯代价均保留。断口内没有连续NMS不会直接中止；不穿第三条原观察边或旧几何，路径不超过端点间距的1.6倍。原图像边界和对角交叉约束保留。
8. 新增简单路径检查：同一网格坐标不得重复出现，内部不得再次踩回原观察脊线。搜索返回这种路径时直接拒绝，不靠后面的C兜底。拒绝首条搜索结果后不继续搜索同一片段对的第二条路径，因此仍可能损失部分候选。

图号、文件名、框、目标类别、图像上下位置、生成RGB都不进入候选生成。区域灰度相容性同样可能受热分布／材料变化影响，不能当作物体身份或边界真值。

## 3. C、R及推断边界

新候选不再因缺口内部平均支持低而在生成阶段提前删除；缺少支持会被记录到原C特征／拒绝原因中。C仍由缺口内点的方向支持、覆盖、跨尺度与端部方向质量，结合竞争连接间隔计算，权重和阈值不变。

因此，能提出一个几何合理的假设，不代表它一定通过C。全无观测支持的长内段仍可能全部被拒绝。当前C是原有未校准代理，不能保证不产生错误结构；新增片段和扩大的候选池也会改变新候选的歧义上下文，但不会改写原候选的C。

R继续复用`prioritize_completion`。片段搜索不使用语义类别，语义／结构重要性只在下游重新加权新增路径。原候选的R和增益逐条不变，错误的高置信语义仍可能影响新边强度。

片段组与幅值组满足原E和旧C/R输出逐像素保留。两个幅值组的新路径、C、R与接纳标记完全相同；幅值不保证彼此逐像素有固定大小关系。

## 4. 单独的固定C重匹配

`rematch_fixed_C`只保护原来已经通过C的路径，释放其余旧几何占用；在原候选池中按原代价尝试没有C拒绝原因的候选。不得删除旧接纳路径，不重算C或R，不搜索新路径。

这个对照有明确限制：原C已经按所有备选计算过歧义间隔，一些备选在重新匹配之前就因歧义被拒绝。只释放端点未必能救回它们；这时不能将“重匹配新增很少”解释为根本不存在可用备选。

## 5. 幅值探针

主片段组的新路径幅值取两端片段原E强度的较小值，之后仍乘C和新增R；它可能继承旧E已受过的重要性衰减。

观测幅值探针在同一候选上，将幅值改为两端原TIR片段方向支持的较小值，再乘相同C和R。它不改变原E、不统一提亮整幅图，也不为弱片段指定人车颜色或固定强度。它只检查编码来源的影响，不能由亮度提升证明真实性。

## 6. 预算对照与评价范围

先完整保留`fragment_completion_seed42_v1`的8192锚点／512搜索预算对照。该预算在所有52张图上截断搜索，在19张图上还截断锚点，不能据其声称完整覆盖新片段候选。

01号开发图的单图预算探针将搜索增至8192：兼容近邻对7117个全部搜索，新候选433→4852，C接纳89→67，继承E的实际新增强度1.81→3.33。扩大候选池会改变歧义分数，因此“接纳条数”不随搜索预算单调增长；这一个已见开发图不能作为泛化结论。

提高预算的v2采用锚点上限16384、搜索上限65536；不改变方向、梯度、区域代价、C或R阈值。每锚点最多4个兼容近邻，所以在这个锚点上限内足以遍历近邻候选集合。是否实际发生锚点／路径状态截断仍按逐图记录核验，不把近邻剪枝、贪心匹配说成全局完备。

最终安全核验在v2的297096条新候选中发现394条回环路径，其中24条曾被几何阶段选用，但**没有一条通过C**，因此回环本身没有写入最终轮廓。它们仍可能占用几何位置或成为歧义竞争项，不能仅因C已拒绝就忽略。

v3在候选进入C前排除这些回环，重算有效池中的C歧义上下文和几何选择。为避免重复全部搜索，使用经源码快照／输入／结果哈希核对的v2冻结搜索记录；保留的路径及原图上下文不变，所以路径重要性R可复用，C、配对和实际轮廓重新计算。固定01号用修复后代码完整重新搜索，与缓存修复的全部浮点条件、路径、C/R及接纳标记逐像素／逐条相同。12组辅助擦边则全部用修复后代码重新搜索，不复用旧接纳结果。

v1／v2保留为计算预算及安全问题的开发中间结果，最终审阅以v3为准。检查记录包括问题清单、修复前源码快照、回归测试和完整重算一致性证据，不以旧版“程序运行完成”代替最终约束通过。

所有52张图使用同一规则：40张既有FLIR开发图与90个原固定裁剪，MSRS／LLVIP训练侧固定各6张无语义回退。40张FLIR已覆盖训练侧全部24个视频，不能当未见视频验证；外部样本没有运行完整FMB语义链。正式test未用于本轮选择参数。

12个擦边控制沿用上轮冻结的同一批位置，所有组都保留原TIR，仅擦掉观察轮廓。它们检验已观测边的可恢复性，不能替代自然弱边／遮挡标注。额外输出擦边局部放大，避免只在全图看不清差异。

真实缺口标注仍可从原图标记工具导入；标注为空时不报告补线正确率、自然缺口召回率、完整泛化或RGB收益。C通过数量、目标框内有新线及更强增量均为诊断描述。

这些目标框是既有定位框，可能包含背景，也不一定原本就有缺口。因此，50/90不能称为修复率，未新增的框也不能直接称为漏补；它只说明新路径比上一轮更能进入这些目标附近。完整类别结果保留，没有只报告人车改善而省略其他类别。

最终FLIR的40图新增252386条合法片段候选，其中5733条通过当前几何／C；加上外部回退共296702条候选、7921条接纳。旧FLIR的1851条接纳路径及旧E、C、R均保留。全部52图无锚点数量、近邻搜索次数或路径状态预算截断；每锚点4近邻和贪心配对仍是实际限制。

重点案例：11_O01大行人框新增20个中心线像素、29个可见增量像素；11_O11也开始有新增。18_O09极小行人仍没有新增；18号两辆车出现少量新增。31_O10车框内新增124个中心线像素，但31_O03自行车仍无新增；31_O01小行人虽有2个新中心线像素，继承E幅值下不达到可见阈值，观测幅值探针才有3个可见像素。不能将这些位置计数替代连接归属／可见边界正确性的判断。

实际增量集中程度另作描述性核对：90个定位框的并集占40图面积的3.66%；其获得的新增强度份额，弱边追踪为1.66%、片段继承E为28.67%、片段观测幅值为17.08%。这提示新片段位置及原E继承都参与了选择性，而非只把同一批背景边统一变亮。但框不是精细前景／边界真值，这些比例不是精度或检测收益。

相同片段路径的观测幅值探针使50个框出现可见变化，比继承E的49框只多1框；其FLIR全图新增强度735.61→2137.89，目标框的强度份额反而下降。当前不因其更亮而采用它，保留为编码对照。

固定C重匹配在52图只多接纳6条旧候选（FLIR5、LLVIP1），90个定位框均没有可见改善；同位置擦边覆盖也维持旧C/R基线的29.7%。它在当前固定C下不是主要收益来源。

辅助擦边需要如实报告退步：片段继承E为39.1%，观测幅值为42.7%，都高于旧C/R基线29.7%，但明显低于上轮连续弱边追踪77.9%。两段锚点与10像素距离约束、旧几何锁定及扩大候选池后的歧义竞争均可能参与这一取舍，目前未单独量化各因素贡献。不能用目标框覆盖增加掩盖这个控制结果。

新增27项检查通过，共享199项、D73项，合计272项；新路径全部不重复坐标、内部不再次经过原观察脊线，旧输入／接纳路径／C/R与同路径幅值控制均已全量核验。验证记录为`verification_v3.json`，固定01号新搜索与缓存重算逐像素一致的证据为`fresh_replay_equivalence_01.json`。

高预算首次完整导出约880秒（52图、90裁剪及12个辅助控制，含计算／绘图／记录），修复后的缓存重算约305秒，不能将这些总耗时当成纯网络推理速度。当前实现仍偏重，若后续质量验证成立，还需单独设计缓存／候选加速和正式训练消融。

当前结论：保留片段候选作为继续审查的分支，固定C重匹配与观测幅值保留为对照；不直接替换D训练默认。下一步需要跨尺度、不同类别、背景负例和不确定位置的独立可见缺口／误连复核，再判断是否值得训练以及应保留哪种候选。真实补线正确率、完整外部语义泛化、RGB质量和检测收益仍未证明。

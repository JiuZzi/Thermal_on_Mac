# 结构选择候选与语义覆盖率诊断

更新：2026-10-23。当前版本是可切换的 `selective_v1` 候选；`joint512` 继续作为默认值和旧训练对照。

## 1. 本轮解决什么问题

旧版的重要性 `R_joint` 主要控制细、粗候选的混合比例。某些杂纹同时出现在两组候选中，仅改变混合比例不能充分抑制它们。多尺度、多个阈值的软响应叠加，也可能让边缘显得较宽。

本轮把“候选选择”和“整体贡献”分开，并检查语义/颜色分支实际上能覆盖哪些位置。模型仍是 conditioned CycleGAN；冻结语义模型、RGB 学得 GMM、微量颜色损失及其训练权重均沿用原实现。

## 2. 新轮廓如何计算

实现见 `pytorch-CycleGAN-and-pix2pix/models/selective_semantic_edges.py`。

原来的细候选 $E_f$、粗候选 $E_c$、纹理密集程度 $D$ 和结构＋语义重要性 $R$ 保持不变。原融合为：

$$
F(E_f,E_c)=\max\left(0.25E_f,\ [RE_f+(1-R)0.5E_c](1-0.4D)\right).
$$

### 2.1 将重要性用于整体响应增益

将既有范围 $R\in[0.18,0.85]$ 归一化，再计算：

$$
r=\operatorname{clip}\left(\frac{R-0.18}{0.85-0.18},0,1\right),\qquad
g(R)=0.25+0.75r.
$$

这样，低重要性不再仅意味着“更多使用粗候选”，也会减弱整体结构条件。最小增益复用既有细边保底系数，未按图号、检测框或测试图调整。

### 2.2 收窄合并后的宽响应

对 $E_f,E_c$ 分别沿红外梯度法向比较前后 1 像素的响应，保留局部脊线、细化平台，再按原软化宽度 1 像素重建距离衰减。重建值由原候选逐像素封顶，因此不会在原候选为零的位置补边，也不会放大原响应。红外梯度接近零的位置回退到原响应。

Canny 本身已有非极大值抑制；这里处理的是多个尺度/阈值合并后的软响应，不是修复“Canny 没有细化”。两个各有局部峰值的平行边仍可能保留，不能承诺消除所有双边。

记收窄后的候选为 $\widetilde E_f,\widetilde E_c$，最终：

$$
E_{\mathrm{selective}}=
\max\left(0.25E_f,\ g(R)F(\widetilde E_f,\widetilde E_c)\right).
$$

**外层保底来自原始、未收窄的 $E_f$。** 初步预览发现，若直接将整个旧轮廓乘以增益，语义漏检的小行人会进一步变暗；最终实现因此保留原版的强度下限。这是保留已有约束，不是为某张图补特殊规则。下限也会保留部分杂纹，且不保证输出与旧版一样亮、边界一样完整。

所有位置满足：$0.25E_f\le E_{\mathrm{selective}}\le E_{\mathrm{joint512}}$。数值变小只是响应选择，不能据此推断边界质量提高。

### 2.3 接入生成器

原语义轮廓、语义着色和 RGB 学得颜色三个入口共用 `contour_from_probabilities()`，在当前裁剪/翻转后的真实 TIR 和循环合成 TIR 上计算同一轮廓版本。

直接输入为 `[TIR, E_selected, 0]`。完整语义和颜色 token 仍通过原独立分支注入；第三通道继续预留给未来结构置信度。新配置进入检查点签名：旧版检查点不能静默当作新版加载，恢复训练也检查版本。

## 3. 语义与颜色覆盖率诊断

实现见 `models/guidance_diagnostics.py`。本轮不放宽 Q 阈值、不改变颜色分布、不新增损失。统计包括：

- 每个预测类别的像素数、平均 Q、Q 非零比例和达到颜色损失阈值的比例。
- 预测类别边界带大小、带内 Q 非零像素数，用于核对边界排除是否生效。
- 提供实际 RGB 先验时，记录受支持类别的颜色损失可用像素；没有先验时，不将语义高 Q 比例当成颜色损失覆盖率。
- 训练时记录条件分支在 dropout、`off` 等处理后的实际非零门控比例。

`learned_color_cycle_gan` 在原损失打印周期写出：

```text
runs/checkpoints/<实验名>/guidance_diagnostics_latest.json
```

该文件覆盖更新，只代表最近一次被记录的真实 TIR minibatch，**不是整个 epoch 的平均值**；不额外运行语义网络、不累计大量诊断文件。Q、类别响应和该统计均不参与反向传播。

Q 是分差、熵、翻转一致性和边界处理组成的启发式可靠度，不是准确率或校准概率。一致、高分的错分仍可能通过；低覆盖率也可能来自保守筛选，不能直接等同于类别分割差。

  --flip-checkpoint runs/pretrained/segformer_fmb_b3/best_model.pth \

本次用原冻结权重实际计算翻转视图。早期缓存的加载器/推理封装代码已有兼容性更新；重新推理全部 40 张原视图，与缓存概率的最大绝对差为 **0**；40 张旧 `joint512` 也与原缓存逐像素一致。新接口遇到源代码差异时必须逐张重推核对，未放宽原图、数据协议、类别顺序或缓存对应检查。

只用单视图时，脚本明确标记为 Q 的上界，不能冒充含翻转一致性的实际结果。加入 `--prior <服务器实际拟合的JSON>` 可补充该先验的覆盖率；本次 40 图报告未使用生产 RGB 先验，故没有声称生产颜色损失覆盖率。

## 5. 训练使用方式与检查

沿用[从零训练完整流程](从零训练学得颜色先验Ubuntu完整流程.md)中的缓存、拟合和训练参数。在**新实验名**的训练命令中加入：

```bash
  --contour-variant selective_v1
```

导出该实验也传入相同参数。省略参数继续使用 `joint512`；原有实验恢复时也保留旧版。新旧轮廓比较使用相同划分、先验、seed、初始化方式、训练预算和验证选择规则。不要在训练中途给原实验换轮廓。

2026-10-23 完成 80 项相关单元/回归检查；另用真实 FMB、真实 RGB/TIR、已有开发先验进行了 128 裁剪的 CPU 两步训练检查：初始零分支输出差 0、新分支/颜色梯度有限且非零、冻结语义模型无梯度、诊断文件成功生成。[实现检查报告](../runs/smoke/selective_contours_20261023/smoke_report.json)。小型 pixel 判别器和开发先验仅用于检查接口与梯度。

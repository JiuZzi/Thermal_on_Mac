# 无边界标注的软轮廓联合训练：JR0 / JR1

## 当前状态

这两版使用 FLIR 的非配对红外/RGB 训练图，不需要像素边界、语义标签或已训练的边缘网络。轮廓修正分支与 CycleGAN 在**同一个训练流程**里更新；没有额外的独立轮廓预训练。显式输入仍是 `[TIR, soft contour, 0]`，第三通道留给后续置信度。

之前 `train_learned_contours.py` 的监督式两版作为独立实验保留；本次的入口是原 `train.py` 加 `--model joint_contour_cycle_gan`。旧 C2b/C2c 代码和权重未替换。

| 名称 | 结构 | 目标函数 |
| --- | --- | --- |
| JR0 / `plain` | 初始软轮廓 + 可学习修正 + 原 GAN | 原 CycleGAN 损失 + 弱轮廓锚点参考 |
| JR1 / `contrastive` | 与 JR0 相同 | JR0 的损失 + 局部软轮廓对比 |

这是研究原型。实现检查通过不代表 FLIR 的轮廓、着色或小目标已经提升。

## 1. 数据流与模块

```text
loader 已裁剪/翻转的红外 I
  → 原 C2c 结构纹理算法（也可选择 C2b）→ 固定初始软轮廓 S0
  → [I,S0] → 轻量修正网络 → logit 修正 r
  → 连续轮廓 S
  → [I,S,0] → 原 RGB 生成器 → RGB
```

修正网络保留原分辨率跳接，只下采样两次。两版结构与初始化一致，包括投影头。JR0 不使用投影头的对比损失；JR1 使用。增强和采样使用独立随机数生成器，不消耗全局数据加载随机序列。

轮廓分数为：

```text
base = clip(S0, 0.02, 0.98)
r = 6 × tanh(residual_head(features) / 6)
S = sigmoid(logit(base) + r)
```

输出头在新训练初始化后置零，因此一开始 `S=base`。极端 0/1 被轻微裁剪以保留可学习梯度。修正既可以增加也可以降低分数；初始 Canny 没找到的位置仍有增加边界分数的路径。限幅不是精度保证。

轮廓分支是 `G_A` 的注册子模块，其参数进入生成器优化器并包含在 `*_net_G_A.pth` 中。真实 TIR→RGB 和 RGB→TIR→RGB 的正向/重建路径都使用它。GAN 反馈可以通过连续轮廓传到修正分支。固定 Canny 初始图本身不求导。

零初始化意味着第一步先更新输出头；编码器的梯度通常在后续步骤出现。已用第二步反向传播检查这个路径，不把第一步编码器梯度为零误判成分支永远不学习。

## 2. 无标签的参考约束

无人工标注不等于没有训练信号。这里用自动生成的启发式锚点，**不将它们称为边界真值或置信度**：

- 正锚点：`S0 >= 0.6`。
- 背景锚点：`S0 <= 0.02`，邻域初始轮廓响应不超过 `0.1`，且原红外局部灰度变化不超过 `0.02`。
- 其余区域：未知，不做锚点参考。

背景必须远离候选轮廓，默认排除半径 3 像素。因此“Canny 没画线”不会自动等于“确定非边界”。但低对比度真边界仍可能误入背景锚点，初始假边缘也可能成为正锚点；这些限制目前未消除。

锚点参考分别对两类求均方误差，再平均，正负区域相互平衡。未知区域仍可从 GAN 和邻域对比得到梯度。参考权重默认 `1.0`，未经真实效果调优。

## 3. JR1 的局部对比究竟作用在哪里

同一红外裁剪再做翻转/90°旋转和轻微灰度扰动；将预测轮廓逆变换回原坐标。初始图也随同变换，避免插值或重新检测带来的坐标偏差。

投影头的输入是**最终单通道轮廓 S**，通过 5×5 卷积提取局部轮廓表示。没有把一个与轮廓输出无关的隐藏特征直接拿来算对比损失。

- 正样本：正锚点所在像素在另一增强视图中的同坐标表示。
- 负样本：远离该位置的启发式背景锚点。
- 其他正锚点不当成负样本，不把未知区域作为直接负样本。
- 双向 InfoNCE，默认 64 个正锚点、128 个背景负样本、温度 `0.1`。

两版目标函数：

```text
JR0: L = L_CycleGAN + 1.0 × L_anchor
JR1: L = L_CycleGAN + 1.0 × L_anchor + 0.1 × L_mapNCE
```

原 GAN/循环权重不变，identity 仍为 0。没有另加语义损失、检测器、闭合轮廓损失或置信度模块。

局部对比促使跨增强的局部表示稳定，并区分候选边界与背景。它不直接判断边缘是否正确，不提供人/车语义，也不保证闭合拓扑。投影头可能承担较多优化工作；非零轮廓梯度只证明连接有效，正式实验还需验证实际作用。

## 4. 已做的实现检查

新增 `tests/test_joint_contour.py` 检查：

- 初始化后仍从原轮廓起步、第三通道为零。
- 翻转/旋转对齐，未知锚点区域不被参考损失监督。
- 初始候选缺失但原图灰度变化强的位置，不直接当作背景。

## 6. 训练过程中看什么

- `contour_active_anchors`：JR1 是否真有对比样本；连续 100 步为零会警告。
- `contour_NCE_raw` / `contour_NCE`：原始/加权对比损失；下降不等于边界更准确。
- `contour_head_grad`：轮廓输出头是否收到梯度。
- `contour_channel_grad`：生成器第一层的轮廓输入通道梯度；不能单独证明依赖轮廓。
- `contour_change_mean`：相对裁剪后初始图的改变量。
- `contour_fraction`：分数 >=0.5 的像素占比；观察全黑、泛滥或内部填满。

训练 HTML 同时显示 `contour_prior`、`contour_refined`、`contour_change`，显示范围正确转换，数值计算始终使用 `[0,1]`。要结合固定小目标、大目标与背景裁剪看图，不仅看损失。

读取检查点旁的 `*_joint_metadata.json` 自动恢复架构/初始轮廓参数；检查初始化、训练数据、预算、更新次数和配置是否一致。输出 float NPZ、软轮廓 PNG、全图及原目标裁剪面板。面板顺序：TIR、C2b、C2c、S0、JR0、JR1、RGB JR0、RGB JR1。各方法统一范围，不逐图归一化。

`--probes` 额外输出轮廓置零、错位、恢复原 S0 的 RGB，以及相对正常输出的平均绝对变化。这个变化用于看模型对输入的敏感性，不是结构正确率。最终需要比较这些干预下的重要目标结构和统一指标是否退化。

旧审查包来自 trainB，可以观察训练过程；不当作独立泛化证据。正式量化用固定 testB，测试集不用于选阈值、挑权重或调损失。

## 9. 断电续训

编号 epoch 检查点旁保存完整 `*_joint_training.pt`，包括优化器、LR 状态、图像池和随机状态；新增磁盘占用需计入实验资源。文件校验防止混用不同保存时刻的网络。

严格预算续训使用**整轮末尾的编号权重**，在原训练命令末尾加：

```powershell
  --continue_train `
  --epoch 20 `
  --epoch_count 21
```

原命令上一行需补上 PowerShell 反引号。预算仍为 `40+40`，不是再训练 80 轮。中途保存的 latest 会拒绝严格续训，提示选编号权重，避免把半轮进度重跑计入不明确的预算。CPU 合成条件下已验证 epoch 边界恢复后的下一步与不中断结果一致；跨机器/CUDA/多 worker 的逐位一致性未验证。

## 10. 创新性：目前能说到什么程度

**判断：有值得验证的研究方向，当前雏形的独立创新强度有限，不能因为增加对比损失就认定有新方法贡献，也不能断言无人做过。** 以下是本次相关工作检索，不是穷尽性首创检索。

| 相关工作 | 已有内容 | 本次方案需要区分的内容 |
| --- | --- | --- |
| [CUT, ECCV 2020](https://www.ecva.net/papers/eccv_2020/papers_ECCV/html/792_ECCV_2020_paper.php) | 局部特征对比与对抗学习联合实现非配对翻译 | 本次在显式单通道连续轮廓的局部表示上对比，且轮廓本身参与条件输入 |
| [Feature fusion + contrastive infrared colorization, 2023](https://doi.org/10.1016/j.optlaseng.2022.107395) | 红外着色中融合细节/语义特征，用对比损失保持内容结构 | “红外着色 + 对比学习”已经存在，不能作为本次新贡献 |
| [CCLGAN, 2025](https://doi.org/10.1016/j.neucom.2025.130713) | 红外无监督着色、全尺度融合和余弦对比 | 需要说明对不可靠轮廓的修正机制与普通特征融合/对比有什么实质差异 |
| [CTSC, 2025](https://doi.org/10.1016/j.optlaseng.2025.109017) | 拓扑语义一致性、图结构、重要 patch 采样与非对称学习 | “关注重要区域”“保持结构”“对比/图学习”都已有先例 |

可发展的核心问题是：**初始轮廓并不可靠，怎样在无边界标注训练下保留重要结构、允许修正错误，并让着色网络选择性利用这些结构。** 当前只有初始轮廓、可学习修正和局部对比；没有实现置信度、真实语义判断、拓扑闭合约束或专门的小目标修复。

要支持贡献，需要证明：

1. 修正后的轮廓确实减少重要目标漏检/错误响应，而非仅为了 GAN 编码其他信息。
2. JR1 优于同结构 JR0，排除网络容量和参考约束的混杂。
3. 轮廓改进确实带来 RGB 结构保留，生成器实际利用该通道。
4. 后续置信度确实反映可靠性，并改善选择性使用；不能直接把注意力、对比相似度或边界分数命名为置信度。
5. 与已有 CUT/红外对比方法和 C2b/C2c 的同协议对照充分，结果不是只在单一视频或单一种子上成立。

建议现阶段把对比学习定位为辅助训练机制，核心研究方向继续是软轮廓与可验证可靠性对着色结构的作用。最终贡献以实验证据及更完整的相关工作比较决定。

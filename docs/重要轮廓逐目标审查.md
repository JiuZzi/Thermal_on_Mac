# 重要轮廓逐目标审查：先查漏检，再决定边界标注范围

这是人工开发审查，不能当作边界准确率或独立测试集评估。现有 FLIR 人车框只用于定位；建筑没有对应框，因此每张图另设一个建筑主结构全图审查项。没有建筑或看不清边界时排除该项。算法、训练代码和数据划分不改变。

## 审查包

默认生成 30 张按视频均衡抽取的常规样本，以及 10 张独立的小目标挑战样本，固定种子 42。常规组并非全体帧的均匀随机样本；挑战组只按标注框尺寸选取，不根据 Canny 或模型结果挑图，也不代表所有低对比、遮挡和纹理困难场景。两组分开汇总。

样本来自 trainB。如已参与 CycleGAN 训练，不得称为独立验证集。第一次审查优先完整 360×288 图；256 中心裁剪可用同一 selection.json 再生成，裁剪移除的边界不算提边漏检。

## Windows PowerShell 生成

在包含 torch、numpy、Pillow、scipy、scikit-image 的训练环境中执行：

```powershell
$thermalRoot = "D:\thermal"
Set-Location "$thermalRoot"

python scripts\review_contour_candidates.py `
  --processed-dir "$thermalRoot\FLIR_datasets\trainB" `
  --manifest "$thermalRoot\FLIR_protocol_v2\manifest.csv" `
  --coco "$thermalRoot\FLIR_ADAS_v2\images_thermal_train\coco.json" `
  --output-dir "$thermalRoot\runs\edge_audit\important_contour_review_v1" `
  --geometry full `
  --sample-count 30 `
  --challenge-count 10 `
  --seed 42
```

已有输出目录不会覆盖，避免丢失审查记录；重新生成请换目录。整个输出文件夹可复制到另一台机器，不要只复制 HTML。

## 如何审查

1. 双击输出文件夹的 `index.html`，先看单独红外图，判断边界可辨认、弱但部分可辨认、无法辨认或无对应目标。框与预处理可能截断目标，只评可见部分。检查 COCO 是否漏框，未定位目标记入备注，不得据此宣称全体目标已审查。
2. 展开对照图。图中为 TIR、9组硬Canny候选的并集、匿名 A/B/C（C1/C2b/C2c），裁剪一致，最近邻放大。红色叠加强度与边缘数值对应，不代表正确性。
3. 先看 ×1，再看统一 ×4 显示，区分完全缺失与弱边。×4 是可视化增益，未改变训练条件。软边距离尾部也会覆盖附近像素，不能据此认定真实边界已找回；仍需观察位置和主体形状。
4. 对候选、A/B/C分别选择：0基本保留、1局部缺失、2大部分缺失或无法判断。以原图确实可辨认的主要边界为依据。细小缺口不等于整目标失败；遮挡、裁剪外部和原图不可辨处不纳入判断。记录缺失部位、位置偏移、疑似噪声边、真实但非关键纹理，二者不要混淆。
5. 默认精简入口只显示前5张图中每图最多3个固定目标（最小行人/骑行者、最小车辆、最大剩余目标），只按框尺寸挑选。熟悉规则后，从顶部切换到全部重点目标、建筑全图审查或完整清单。精简入口未覆盖的目标不能算已通过。完成前不要点击方法对应关系。请老师复核部分相同目标，并记录有分歧的项。
6. 点击“导出审查结果 JSON”保存。浏览器缓存仅作临时保存，换浏览器、改路径或清缓存后请导入导出的 JSON。建筑项与目标项、常规组与挑战组分开解释。

无需逐像素画边界。这个阶段的主观等级不能写成边缘召回率、精确率或像素准确率。

## 汇总

```powershell
python scripts\review_contour_candidates.py `
  --output-dir "$thermalRoot\runs\edge_audit\important_contour_review_v1" `
  --ratings-json "$HOME\Downloads\contour_review_ratings.json"
```

只汇总原图边界可辨、且候选与三个方法都完成0/1/2评级的相同审查项；未审查、无法辨认、无法判断项不混入比较。生成 `review_summary.json`，按抽样组和类别报告等级计数，并列出需复核的失败案例，不自动宣布质量合格。

- 候选并集大部分缺失：优先检查提边阶段；单纯置信度乘法不能补回这些边界。
- C2b基本保留而C2c大部分缺失：检查加权误伤，同时确认不是显示变暗或候选偏移的错觉。
- 候选基本存在、主要问题为干扰线索：可以进入简单置信度对照。

正式量化时，优先为这些反复出现的失败类型和一组独立抽取的正常目标标少量边界；不能只标失败例再把结果当作整体准确率。候选并集也不是检测能力的理论上界；距离软化和容差匹配会影响后续边界指标。

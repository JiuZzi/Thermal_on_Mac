# 区域证据与拒绝决策约束的轮廓补全：待验证方案

日期：2026-10-30。

状态：最初为源码、最终v3缓存与原始文献核查后的研究建议。现已按用户授权实现第4节前三步并完成独立开发预览，详见[前三步实现与完整结果](区域证据补边前三步实验.md)。结果有取舍，区域拟合的独立贡献很小；尚未改变D训练条件或引入学习模型。下文保留最初方案，文中的机制是本项目的工程设计假设，并非所引论文的原算法。

## 1. 当前结果支持什么判断

现有片段法改善了新增线段进入目标附近的能力，但12个相同辅助擦边控制的可见覆盖率，从连续弱边追踪的77.9%降到39.1%。90个目标框内有新接纳中心线的数量从3增到50，不能解释为50个缺口被正确修复。详细基线见[片段实验记录](片段补全与独立重匹配对照.md)。

本轮额外读取`fragment_completion_seed42_v3/diagnostics/01_fragment.json`至`40_fragment.json`，只统计新片段候选，结果如下：

| 项目 | 数量 | 解释 |
|---|---:|---|
| 合法新候选 | 252386 | 仍可能是假连接或无必要的连接 |
| 几何选中 | 53354 | 现有代码会先占用位置，再决定C是否接纳 |
| 满足全部C条件 | 5814 | 未经独立正确率校准 |
| 最终接纳 | 5733 | 不是正确边数量 |
| 满足C但未被几何选中 | 81 | 只改变匹配时可利用的当前候选很少，且不保证都能加入 |
| 重复几何路径记录的冗余数 | 31297 | 相同网格路径可有不同片段端口、来源及上下文，需要合并几何并保留元数据 |
| 几何选中者触发低分拒绝 | 47505 | 与其他拒绝原因可能重合 |
| 几何选中者触发歧义拒绝 | 40660 | 与其他拒绝原因可能重合 |

重复统计方法：将新候选的完整`path_yx`序列与其逆序取字典序较小者作为键，每个键累计`记录数-1`。它仅识别完全相同的几何路径，不将近似路径也算重复。不同端口解释仍可能有不同切向或区域信息，不能删除这些元数据，也不能把重复记录当多份独立证据。当前统计不能证明重复记录造成了多少真实漏补，须另做消融。

因此，下一步应优先检查重复假设、C的证据定义以及两种候选机制的互补性。全局匹配可以后续研究，当前固定C下它不是主要瓶颈。

## 2. 跨学科依据与借鉴边界

### 2.1 视觉心理物理与随机补全场

[Williams与Jacobs，1997，Stochastic Completion Fields](https://www.cs.unm.edu/~williams/lance-1997-1.pdf)在位置—方向空间对连接片段的路径建模。可借鉴的是对方向连续的多个路径解释进行比较，而非只依赖最近距离或一条最短路。模型内部的路径分布不等于真实红外边界正确概率。

[Rezanejad等，BMVC 2021，Contour-guided Image Completion with Perceptual Grouping](https://arxiv.org/abs/2111.11322)已用现代化SCF完成轮廓并引导图像修复。因此，关联场、完形补边、再指导生成的组合已有先例，不能将这一描述本身作为首次提出的创新。

### 2.2 视觉神经科学中的边界归属

[Zhou、Friedman与von der Heydt，2000，Coding of Border Ownership in Monkey Visual Cortex](https://pmc.ncbi.nlm.nih.gov/articles/PMC4784717/)表明，猴视觉皮层部分神经元的响应受到边界属于哪一侧图形及更大范围上下文的影响。

本项目可借鉴为：判断一条连接时，同时检查两侧区域的延续关系。局部区域一致性只是代理，不能据此确认物体身份、深度次序，或声称实现了相同神经机制。真实道路裂纹也可能有可靠的两侧分隔，它是否值得强调仍由R决定。

### 2.3 低信噪比图像的区域与边界联合建模

[Field of Junctions，ICCV 2021](https://arxiv.org/abs/2011.13866)联合表示边、角点、交汇和区域，并通过重叠小块之间的一致性约束提取低信噪比结构。

[Boundary Attention，2024论文版本](https://arxiv.org/html/2401.00935v3)进一步学习局部几何和自适应窗口，可从简单合成形状学习并在自然低照照片中提取边界；输出还包含区域关系及重叠块的分歧信息。其可见光结果不证明热红外迁移有效，参数量小也不保证高分辨率时显存小。若引用正式会议版本，应标明ECCV 2024 Workshops，不能写作ECCV主会论文。

对本项目最有用的启发是：在一个区域内累积弱分隔证据，保留转角、细条和交汇，避免只读取每个缺口像素的梯度值。可以先实现局部拟合版本，再单独检验是否值得引入学习式边界证据。

### 2.4 统计决策中的拒绝选项

[Chow，1970，On Optimum Recognition Error and Reject Tradeoff](https://research.ibm.com/publications/on-optimum-recognition-error-and-reject-tradeoff)研究错误与拒绝之间的权衡。可借鉴为：比较连接候选时，明确包含“不连接”选项，并评价覆盖率和误连率的关系。这不能使一个启发式分数自动成为校准概率。

## 3. 建议方法

暂称“区域证据与拒绝决策约束的轮廓补全”。核心问题是：一条连接是否比不连接更能解释红外观测，以及它在相邻解释中是否足够明确。

### 3.1 保留两类候选，统一管理同一连接

1. 观测追踪候选：沿实际弱脊线恢复尚未保留的边，允许只有一个原锚点的局部延伸。保留上一轮对连续弱边的优势。
2. 缺口连接候选：由两个可靠片段约束短连接，允许内部没有连续NMS。
3. 合并完全相同的几何记录，再研究近似路径的分组。保留所有来源、端口和上下文，不因两个机制来自同一幅TIR就宣称证据独立或置信度翻倍。
4. 在同一局部缺口中区分“同一连接的不同表示”和“连接到不同片段的竞争解释”。前者不应仅因记录多就受到额外歧义处罚；后者必须继续接受竞争检查。

两个候选池合并只扩大待审查集合，不代表两组接纳结果直接取并集，也不保证恢复77.9%的控制性能。

### 3.2 从端部两侧均值扩展到整段区域证据

当前`fragment_completion.py`已有端部两侧均值代价，但它主要调整候选优先级，尚未验证整条假设是否形成合理分隔。

拟沿候选两侧建立局部带状采样区域，并比较：

- H0：此处无新增分隔，用一个平滑区域模型解释观测。
- H1：此处存在该候选边界，用边界两侧分别平滑的区域模型解释观测。

比较应使用噪声归一化的稳健残差，并对H1增加的自由度施加复杂度惩罚或使用留出像素评价。否则两侧模型参数更多，可能仅因过拟合噪声而胜出。H0也要允许缓慢灰度变化，避免将道路光滑热变化强行切成边。

支持一个连接的条件包括：局部区域解释得到实质改善、两侧沿程保持合理延续、端点方向相容，并且没有可靠观测冲突。热极性变化或两侧不够均匀应首先视为证据不充分，不能一律硬拒绝；T/Y交汇也应允许第三个区域或保留未知，而非把所有边强制解释成两区域直线。

如果两侧观测都无法区分，几何平滑本身不足以证明应补出可见边。遮挡后的隐藏物体轮廓不在当前可见边恢复的主张内。

### 3.3 重新定义C，区分缺少证据与观测冲突

当前C包含缺口内部的梯度覆盖率及连续无支持长度硬条件。扩展候选机制后，这些条件会限制其跨越真正缺口的能力，但不能直接降低所有阈值解决。

建议保留证据来源：

- C_obs用于观测追踪：检查沿程方向支持、跨尺度证据和稳定性。
- C_gap用于跨缺口连接：联合端片段质量、区域分隔改善、方向／曲率、有效竞争假设及观测冲突。
- 明确无有效证据时保留未知或不补。跨可靠边界、错误连接归属等冲突需要另行处理，不与低梯度混成同一个原因。

两类分数需要共同的决策尺度或分别明确其拒绝规则，不能直接取较大者冒充正确概率。若拟合成概率，应先定义独立的真实可见边事件，在按视频隔离的开发／校准数据中拟合，并在另一个留出集评价。合成擦边只能辅助训练与控制，不能独自校准自然缺口正确率。

### 3.4 允许多个局部路径解释及不连接

可借鉴SCF，在位置—方向空间内保留少量相异的短路径，比较其区域和观测解释。局部解释一致可作为集中程度线索；多个端点或不同路径同样合理时允许拒绝。

集中程度不等于真实性：一组方法可稳定地犯同一种错。扰动、跨尺度与跨块一致性也都是同源证据，不作为独立传感器投票。

新候选先检查其可采纳性，再参与端点占用和交叉冲突选择，避免被C拒绝的候选先占住新位置。初始对照继续冻结旧基线，单独检查这一变更；若后续联合重审旧接纳结果，必须另列实验。

全图局部区域证据可一次计算后供多个候选共享，候选多假设搜索限于小连通分量，并记录预算与截断。当前52图完整预览包含大量CPU搜索和诊断，额外多路径不能无成本加入。

### 3.5 保持重要性、可靠性与幅值的职责

R决定值得强调哪些结构，C决定新增连接是否可信，Q决定语义条件可依赖程度。高人车重要性不能将不可信连接变为可信连接。

保留原始E_obs和独立TIR内容路径，新增路径单独保存来源、C及R。相同R不在新增幅值中反复计算。幅值来源改变仍需独立对照：此前观测幅值探针变亮，同时新增强度在原目标框中的份额下降，不能直接采用更亮者。

## 4. 最小实施顺序

1. **固定候选，检查重复表示。** 使用v3缓存，仅合并几何等价记录、保留元数据，核对C竞争项与接纳变化。所有其他公式和原基线冻结，不增加搜索预算。
2. **固定去重后的候选，测试区域证据。** 对照旧C与加入区域模型比较的C；保留不连接选项。先在独立自然可见缺口、负例和不确定样本中检查排序／拒绝效果。
3. **检查两种候选机制的互补性。** 比较弱边追踪、片段法、两者统一筛选。继续使用原12个擦边控制，但不围绕其位置调参。
4. **再决定是否增加学习式证据或SCF多路径。** Boundary Attention的现成模型或合成几何训练是单独分支，先核实依赖、权重、热红外适配及速度；不将其加入视为必然改善。
5. **轮廓评价通过后再接D。** 固定同一扩散骨干、预算和条件强度，检查图像结构、错误新增目标、颜色及下游检测增量。

这使重复记录、区域证据、候选互补、多路径推断和学习式边界证据有独立归因，不要求一次全部加入。

## 5. 泛化与评价

- 开发、校准和最终测试按视频／场景隔离。现有40张FLIR图已见，不充当新方法泛化证据。
- 独立复核自然可见缺口、错误连接负例与未知位置，覆盖不同尺度、类别、背景及无人车场景。框内新增、闭合率和更亮都不能替代正确率。
- 首先比较相同误连率下的自然缺口召回，再报告路径级错误、像素级边界位置、保留比例和计算成本。若用概率解释C，额外评价校准。
- 外部数据使用同一冻结设置。现有MSRS／LLVIP各6张仅为无语义结构回退，不证明完整语义链的泛化。
- 极小目标先检查原始分辨率。可用全图一致分块与尺度映射减少下采样损失；不能只为18号框手写规则。若原始TIR也没有可辨线索，算法不能保证恢复真实边界。
- 如果采用合成几何训练，随机曲线、细条、转角、遮挡、噪声、模糊与热极性应覆盖多种组合；还要留出形状家族和真实传感器数据评价，不能由合成训练直接宣称跨域成功。

## 6. 可以主张的研究贡献候选

拟研究的重点是：面向热红外弱结构，将观测追踪与缺口推断区分建模；以局部区域解释、竞争假设和拒绝机制构建可追溯的新增结构条件，并检验其是否改善生成的结构保持和错误结构传播。

这比仅增加几何规则更有明确的问题定义，但新颖性仍需系统相关工作核查，性能与幻觉抑制仍需实验。不能声称首次使用认知启发、SCF、补边引导生成，或证明完全消除幻觉。

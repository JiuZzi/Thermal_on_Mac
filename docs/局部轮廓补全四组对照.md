# 局部轮廓补全：第一版实现与固定四组对照

日期：2026-10-29。当前是独立开发预览，不改变D的默认E、条件缓存配方、训练损失、第三通道或已运行实验。正式diffusion仍使用`[TIR,clarity_v1,0]`。

## 1. 当前完成范围

新增`models/contour_completion.py`，只依赖现有NumPy/SciPy/scikit-image，不加载新模型，不训练评分器。输入为原始TIR、原有浮点软轮廓E及未加重要性权重的候选脊线；不接收框、文件名、目标类别或生成RGB。语义仅通过原有E间接参与，本轮不使用P/Q对补线作硬否决。R、语义可靠性Q与新增结构评分仍分开。

解决目标是已有片段之间的局部可见缺段。完整缺失物体、长距离遮挡后的隐藏表面、人体／车轮模板推断及全局语义纠错不在本版实现范围。脚底或轮胎与地面接触处不要求强制闭合。

| 组 | 算法 | 用途 |
|---|---|---|
| observed | 原有clarity_v1逐像素保留 | 不补边基线 |
| closing | 同一脊线上的方形二值闭运算，新增区域作保护原脊线的细化 | 简单形态学对照；不以梯度判断补线真实性 |
| geometry | 端点方向＋原图证据＋方向状态路径搜索＋冲突检查 | 观测支持的局部补全候选 |
| reliable | 对geometry中同一批已选路径作固定评分、拒绝与衰减 | 独立检验可靠性筛选，不重新搜索替代路径 |

## 2. 候选与路径

1. 复用clarity的细／粗候选及原始细脊线，合并、细化，在原有E的邻域支撑下提取端点。图像截断端点不作为缺口，过短片段不估计方向。
2. 沿端点后的片段用PCA估计外向切线和方向质量，并检查其与原TIR方向证据是否相容。语义漏检不会直接关闭候选；低于原有锚点支撑阈值的片段仍可能漏掉，不能声称解决了所有弱行人问题。
3. 搜索距离按短边的0.035缩放；360×288时上限为10.08像素。端点方向最大偏差65度，路径长度不超过直线间隔的1.6倍。
4. 在局部`(y,x,方向)`状态中作确定性A*，代价包含长度、方向相容的红外梯度支持和转弯惩罚。不能穿过第三条已有脊线，不允许通过对角缝隙越过观测交叉。
5. 按代价确定性贪心选择不冲突路径，一端点最多一条连接；同时检查新增路径相交及对角交叉。不是全局最优匹配。没有合格连接时保持原轮廓，不设“每图必须补多少”的目标。

每端点最多4个邻点，每图最多512个搜索，每对最多6000个展开状态。超过上限有明确计数／拒绝原因，不静默宣称完整搜索。当前40图无图级候选搜索截断；个别路径仍可能因状态预算、冲突或不可达而拒绝。

## 3. 观测支持与可靠性代理

原TIR以三尺度平滑后求梯度；强度相对于梯度自身、Haar噪声代理与1/255数值底线归一化，不按图像最大值或分位数拉亮。使用候选法向与梯度的绝对夹角关系，允许热红外／可见光对比反转。

路径评分只检查新增内点，不让两个强锚点给中间空白缺口背书。方向取缺口邻域的平滑切线，避免逐像素锯齿沿无关横向强边取得虚高支持。

固定评分由平均方向支持0.40、支持覆盖0.25、跨尺度一致0.20和端点切线质量0.15组合，并按竞争连接的代价间隔衰减。默认再要求评分≥0.58、支持覆盖≥0.45、最长无支持段比例≤0.65、竞争间隔≥0.08。所有参数在生成开发预览前固定，没有按11/18/31或某个类别另写规则。

这些数值是首版工程起点，并非已证明最优的阈值，也没有独立真值校准；同图多尺度证据相关，不能解释为独立传感器融合或真实概率。真实树枝、道路纹理可能通过筛选；本评分判断连接支持，不替代任务重要性R。高可靠候选也不保证生成器没有幻觉。

## 4. 来源、编码与对照一致性

输出保留`observed`、各组新增浮点边、各组新增中心线mask、候选评分图、每条路径坐标、端点／代价／评分及拒绝原因。新增来源在路径生成时记录，不根据原有软边是否为零推断，因为高斯尾部可原本非零。

融合使用`max(E_obs,E_add)`，不削弱原有轮廓、不统一提高全图强度。新增强度不超过两端原有支撑强度的较小值；第四组再乘可靠性评分。每条路径单独作σ=0.5的高斯软编码，再取最大值，保证逐像素`E_obs ≤ E_reliable ≤ E_geometry`。若把不同强度的所有脊线一次交给最近邻距离变换，删除近处弱线反而可能让远处强线变亮，本版明确避免此问题。局部渲染截断到八倍σ，相对尾部低于约1.3e-14。

闭运算使用相近的局部距离预算，不引用方向或TIR支持。细化仅能删除新增像素，原脊线全部保护，避免把原有边位移后的中轴当作新边。形态学填满的窄区域仍可能留下密集新增像素；“编码σ相同”不表示局部物理线宽必然相同。

本轮仅导出独立条件预览，不注册新训练variant，不把候选当真值，不将C送入当前零通道。未来接入D时需区分原观测边与新增段的损失，新增段方向应来自路径且受可靠性调节，不能直接用缺段处不可靠的原TIR梯度作为同等强度监督。需要新配置／缓存／run并保持匹配对照。

## 6. 跨学科依据与验证边界

第三组借鉴视觉关联场／良好连续性，将方向与平滑延续变成约束；曲率惩罚也对应弹性曲线的数学正则。第四组借鉴错误—拒绝决策与可靠性加权。不是复现人类神经机制，也不把这些已有原则本身称为首创。

- [Field等，1993：关联场实验](https://doi.org/10.1016/0042-6989(93)90156-Q)
- [Williams与Jacobs，1997：随机补全场](https://www.cs.unm.edu/~williams/lance-1997-1.pdf)
- [Chen等，IJCV 2017：方向与曲率约束最小路径](https://arxiv.org/abs/1612.00343)
- [Rezanejad等，BMVC 2021：SCF补全引导图像修复](https://arxiv.org/abs/2111.11322)
- [Chow，1970：错误与拒绝权衡](https://research.ibm.com/publications/on-optimum-recognition-error-and-reject-tradeoff)

实现检查涵盖已知直线／圆弧缺口、平行端点、横向强边干扰、已有边界交叉、无观测支持、搜索预算、极性／翻转、来源追踪、同候选单调筛选及实际导出。测试通过只能支持这些约束与已构造情况，不保证任意输入无bug或真实补线全部正确。最终结果和测试计数以本轮验证记录为准。

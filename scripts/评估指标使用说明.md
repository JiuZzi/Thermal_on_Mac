# NTIR→RGB 统一评测：CycleGAN、PearlGAN、MornGAN 与 C0-C5

评测与训练代码解耦：任一模型只要对 `testB` 的固定 112 张热红外图生成 RGB，并遵守同一输出命名规则，就可使用同一套指标。

## 固定数据协议

- TIR 输入：`FLIR_datasets/testB` 的 112 张图；不允许跳图。
- RGB 表观参考：`FLIR_datasets/testA` 的固定 696 张白天 RGB 图。
- 所有方法必须固定测试集、输出尺寸、预处理和随机种子。
- `testA` 与 `testB` 无配对；禁止以它们计算逐图 PSNR、SSIM、LPIPS。

## 一条命令：FID、KID、APCE-Py 与 Edge-F1

先在**运行评测脚本的同一个 Python 环境**安装依赖：

```zsh
cd /Users/tanwenjie/代码/thermal
python -m pip install -r scripts/requirements_metrics.txt
```

CycleGAN BtoA 的结果名为 `<TIR-stem>_fake_B.png`。C0 的正式测试完成后运行：

```zsh
python scripts/evaluate_distribution.py \
  --tir-dir FLIR_datasets/testB \
  --generated-dir runs/results/flir_v2_c0_cyclegan_40_40/test_latest/images \
  --generated-suffix _fake_B.png \
  --reference-rgb-dir FLIR_datasets/testA \
  --output-dir runs/evaluations/flir_v2_c0_cyclegan_40_40
```

PearlGAN 或 MornGAN 若保存为与输入相同的文件名，改为 `--generated-suffix ''`。脚本会严格检查每张 TIR 是否存在对应结果，缺一张就报错。

输出文件：

- `evaluation_manifest.csv`：112 张 TIR 与生成图的映射；
- `metrics.json`：FID、KID、APCE-Py、Edge Precision/Recall/F1、参数、设备和版本；
- `edge_threshold_metrics.csv`：99 个阈值下的完整边缘结果，可画曲线。
- `metric_report.png` 与 `metric_report.pdf`：在评估命令结束时自动生成，包含四项最终指标、箭头方向和 99 阈值边缘曲线；无需再运行绘图命令。

FID、KID 越低越好；APCE-Py、Edge-F1 越高越好。FID/KID 仅表示生成图整体分布接近白天 RGB 域，**不证明**某张生成图恢复了夜间场景的真实白天颜色。当前只有 112 张生成样本，KID 是主指标，FID 是补充。

## APCE-Py 与 Edge-F1 的定义

对每个高阈值 `0.01:0.01:0.99`，令低阈值为高阈值的一半。只对热红外边缘非空的图像求平均；这与 PearlGAN APCE 的阈值扫描和聚合公式相同。

\[
P=\frac{|E_{RGB}\cap E_{TIR}|}{|E_{RGB}|},\quad
R=\frac{|E_{RGB}\cap E_{TIR}|}{|E_{TIR}|},\quad
F1=\frac{2|E_{RGB}\cap E_{TIR}|}{|E_{RGB}|+|E_{TIR}|}.
\]

`APCE-Py` 是 99 个阈值上的平均边缘召回率 `R`。它高、但 Edge-F1 不高时，往往代表模型画出了太多缺乏热红外依据的伪边缘；两者同时提高才是可信的结构改善。

Python 版使用 `scikit-image.feature.canny`，因此它适合 C0-C5、PearlGAN、MornGAN 的**内部统一横向比较**。它不应直接与 PearlGAN 论文或官方 MATLAB APCE 数字混用；若论文定稿时需要官方复核，可额外运行 `pearl_apce_and_edge_f1.m`。
